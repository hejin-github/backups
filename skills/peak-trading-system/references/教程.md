## 第1章 总览：这套教程教你什么

一句话：**先学会用数学拆穿"X年Y倍"，再从三位高手身上提取可落地的规则，最后用索普的期望值与仓位公式把这些规则变成不破产的仓位。**

学习路径（每章 10–15 分钟）：

1. 第2章 官方比赛是什么、战绩怎么核验——建立"榜单口径 ≠ 实盘可持续收益"的认知底座
2. 第3–5章 三杰策略体系——钧哥（题材挖掘+中低位低吸）、童辰（冰点半路）、六个核弹007（小市值打板+低吸）
3. 第6章 索普概率论与仓位管理——期望值、盈亏比、Kelly、回撤数学
4. 第7章 三年回测证据——三套近似策略到底跑出什么结果
5. 第8章 实战清单与复盘模板——可直接执行的部分
6. 第9章 常见错误与误区——先学会不死，再谈赚钱

核心结论预告（先记住这四条）：
- 近似回测里**没有任何一套跑赢中证500（+28.15%）**；最好的"小市值短线"变体（+16.59%）也略输沪深300（+17.17%）。
- **仓位管理不能创造 edge，只能保护 edge**——索普仓位变体在弱信号下几乎不开仓（仅20笔、胜率10%）。
- 榜单数字是"自报+可手调账本"，**不是监管或交易所认可的实盘名次**。
- 真正能带走的不是他们的"倍率"，而是**期望值思维 + 严格止损 + 分数仓位**这三件套。

## 第2章 官方比赛与战绩核验

### 2.1 比赛是什么

- **活动**：2025年（第五届）操盘风云巅峰会暨战略联盟启航盛典，2026年1月2–4日在上海中心大厦举办。
- **主办**：操盘风云（运营主体为广西大家实盘文化传媒有限公司）——**不是同花顺官方主办**。
- **数据支持**：同花顺投资账本（工具支持方，**不对收益真实性作背书**）；媒体支持：华尔街见闻、财联社、摩尔投研、投顾网。
- **榜单性质**：按累计收益率排序的"名人堂式"榜单，每位选手的起止日期**由其在账本中自选绑定窗口决定**；同一位选手可多段记录同时上榜（童辰2条、六个核弹007 2条、kokokolo8 3条）。巅峰赛官方赛程为2024-07-26至2026-12-31，但榜单里有2016年就开始的记录——**不是同期同规则PK**。

### 2.2 数据怎么来的（可信度核心）

| 环节 | 实际做法 |
|---|---|
| 每日报单 | 选手每日09:30–24:00上传持仓截图，系统OCR识别；截图不得打马赛克 |
| 账户验证 | 前十账户+前五十随机抽验：选手本人登录同花顺投资账本提交参赛期间收益曲线及交割单 |
| 账本能力 | 同花顺投资账本官方说明支持"交割单批量导入历史流水 + **手动调整持仓数据**" |
| 独立审计 | **无**：未找到任何第三方独立审计、券商API只读同步、异常交易审查的公开披露 |

### 2.3 核验三问（对任何"X年Y倍"先问）

1. **有无券商盖章交割单 / 可独立核验的逐笔流水？** 没有 = 数字无法独立复核。
2. **窗口起止是否自选？** 自选起点 = 可以从低谷重启或从峰值起算，专挑好看的一段。
3. **同选手是否多账户/多段上榜？** 多段混排 = 对外展示的可能是表现最好的那一段。

### 2.4 复利数学检验（方法）

给定总倍数 M 与时长 T（年或交易日数）：
- 年化倍数 = M^(1/年数)
- 月化复利 = M^(1/月数) − 1
- 日化复利 = M^(1/交易日数) − 1

对照 A 股约束：主板±10%/创业板·科创板±20%涨跌停；单次完整买卖摩擦成本约0.1%~0.15%（佣金万2.5双边+卖出印花税0.05%）；小盘股滑点1%~3%常见。**日化≥1.5%且连续一年以上、期间无显著回撤 → 数学上接近不可能（红旗）**；日化≤0.3%属于"精英但可想象"区间。

## 第3章 钧哥_天下无双：题材挖掘 + 中低位低吸

### 3.1 人物与战绩

- 2018年入市，前三年亏掉约90%（三次腰斩），2021年起自称未再亏损；2025届巅峰会总榜冠军，官方口径三年 +552976.22%（约5530倍）。
- **口径矛盾**：同一事迹四个时点四个数字——25倍（2025-01）→ 525倍（2025-03）→ 1062倍/28个月（2025-10韭研公社）→ 5529倍（2026-01），最大差距221倍，官方未解释。

### 3.2 交易体系（他的原话要点）

- **不打板、不追龙头、不做超短**（"不做一进二进三、不做龙头空间"）。
- 核心：**新题材挖掘与预判**——每天复盘韭研公社/雪球/各论坛全部消息，筛出关键信息→找板块题材→找核心个股。
- 买点：**中低位低吸（DC）与半路为主**；不看指数涨跌与情绪（指数暴跌3个点以上才敏感）。
- 仓位：约**1/3**；卖出没有固定锚点，判断"没人愿意用更高价接筹码"就全部卖出；龙虎榜仅作参考不作买卖依据。
- 第一法则：**控制回撤、保住本金**；单月最大回撤十几个点。
- 自述案例：东兴股份（提前挖掘、公告成功后兑现、留一周翻倍离场）。

### 3.3 能带走的规则（可程序化近似 V1）

| 环节 | 规则（近似变体） |
|---|---|
| 题材代理 | 近30日出现涨停（"新题材/首波"无客观算法，用涨停替代） |
| 买点 | 当日收跌（绿盘）低吸、当日非涨停非跌停 |
| 仓位 | 单票≤33%，最多2只 |
| 卖出 | 自高点回撤-10%移动止损；3日不创新高且亏损离场；持仓7日到期 |
| 回测结果 | 累计-0.28%、年化-0.10%、最大回撤-41.3%、胜率32.9%、盈亏比2.13、258笔 |

**教训**：去掉"人工题材认知"后，规则只剩"涨停后绿盘买入"的弱均值回归，反复被止损——**他的 alpha 在信息筛选与认知里，不在买点上**。这正是"策略可程序化程度黄旗"的由来。

## 第4章 童辰：冰点过滤 + 低位半路

### 4.1 人物与战绩

- 总榜亚军，主榜 2016-06-15 至 2025-09-03（约9.2年）+80890.37%（约810倍），副榜6年 +9815.69%。年化≈106.8%、日化≈0.30%。
- 自述胜率约46%、靠盈亏比拉动；2018年曾回撤62.8%。9.2年不间断年化107%属顶尖，但2016年起点的"美化"可能。

### 4.2 交易体系

- **冰点过滤**：市场情绪冰点（涨停家数极少）时才出手，避免高位接力。
- 买点：**低位半路**（股价处于120日低位附近、60日内有涨停基因、当日涨幅5%~8%的半路，非涨停板追入）。
- 止损：**-4% 机械止损**，5日持仓到期。

### 4.3 可程序化规则（V2）

| 环节 | 规则 |
|---|---|
| 情绪过滤 | 样本池当日涨停家数≤3（全市场口径不可得，用样本池代理） |
| 位置 | 收盘价 ≤ 120日最低价×1.25 |
| 涨停基因 | 60日内有涨停 |
| 买点 | 当日涨幅∈[5%,8%) 且未涨停 |
| 止损/到期 | -4%止损；5日到期；最多3只等权 |
| 回测结果 | 累计+6.51%、年化+2.21%、最大回撤-18.3%、胜率43.0%、盈亏比1.51、93笔 |

**教训**：冰点+低位的"防守型"结构回撤可控，但胜率43%+盈亏比1.51的期望很薄（EV/R=0.43×1.51−0.57≈0.08），在真实成本与滑点下几乎白忙——**盈亏比不足1.5时，胜率必须显著超过40%才值得做**。

## 第5章 六个核弹007：小市值打板 + 低吸

### 5.1 人物与战绩

- 真名**凌国民**（绍兴网+中华网交叉印证），2011年底入市，2018年杠杆二次归零；2025届总榜季军。
- **关键口径矛盾**：颁奖口播72233.05%（722倍）vs 本人演讲PPT/绍兴网/中华网/B站官方片段全部是1750.99%（17.5倍，一年四个月）——相差41倍，官方从未解释。若722倍按1.33年折算日化1.95%（数学上接近不可能，红旗）；其本人主动披露的17.5倍（月化19.6%）属顶级游资水平（黄旗）。

### 5.2 交易体系（可程序化程度最高的一套）

**选股（首板模式）**：
- 市值<100亿；股价<20元（优选<10元）
- 历史低位+放量突破（近250日价格分位<30%附近、突破年线/前高）
- 当日量 ≥ 前15日均量2倍（避免 >5倍爆量）
- 过去1年涨停≥3次（有涨停基因）
- 板块当日涨停家数≥3家才考虑（只做核心板块核心龙头）

**高低切换**：情绪好做连板接力（一进二/二进三/三进四，三板以上看炸板后回封）；情绪差做首板——情绪阈值未公开。

**仓位与止损**：单票5%~10%，同时≤3只，持股≤5天；机械止损-6%（最大-7%）；破5日均线止损；打板未封板次日竞价止损。

### 5.3 可程序化规则（V3，小市值短线）

| 环节 | 规则 |
|---|---|
| 市值/价格 | 流通市值<100亿、股价<20元 |
| 量能 | 量比∈[2,5] |
| 涨停基因 | 250日涨停≥3次 |
| 买入 | 当日涨幅<9%且未涨停（半路/低吸替代打板） |
| 止损/到期 | -6%机械止损 或 破MA5；5日到期；单票10%、最多3只 |
| 回测结果 | **累计+16.59%、年化+5.46%、最大回撤-6.8%、胜率38.1%、盈亏比3.06、夏普0.69、84笔** |

**教训**：这是三套变体中风险调整后最优的——**低胜率(38%)+高盈亏比(3.06)+小回撤(-6.8%)** 的经典"截断亏损、让利润奔跑"结构。但它仅84笔、样本小，实盘小票冲击成本可能远大于回测假设的±0.2%滑点。**它证明的不是"打板能暴富"，而是"小市值+量价过滤+机械止损"在结构上健康。**

## 第6章 索普：概率论、盈亏比与仓位管理

### 6.1 核心公式（必须背下来）

- **期望值**：EV/R = p·b − q = p·(1+b) − 1，其中 p=胜率，q=1−p，b=盈亏比（平均盈利÷平均亏损），R=单笔初始风险。**EV/R ≤ 0 不做**——不是"我觉得会涨"。
- **盈亏平衡胜率** p* = 1/(1+b)：b=1.5 时 p*=40%；b=2 时 p*=33.3%；b=3 时 p*=25%。
- **Kelly 最优仓位** f* = (b·p − q)/b = p − q/b。全Kelly最大化对数增长率但回撤常见50%+；**索普实务用半Kelly（α=0.5）**——保留约75%增长率、波动减半。
- **回本涨幅** = 跌幅/(1−跌幅)：−50% 需 +100% 回本；−90% 需 +900%（实操放弃）。

### 6.2 两个量化反例（散户死法）

1. **高胜率死法**：胜率70%，但赚3%就跑、亏20%死扛 → b=0.15，EV/R=0.70×0.15−0.30×1 = **−0.195**。70%胜率照样长期每押1块亏0.195块。
2. **满仓连亏**：满仓连吃5个-10% → 0.9⁵=0.5905，回撤40.95%，回本需+69.4%；单笔风险2%连亏10笔 → 0.98¹⁰≈0.817，回撤18.3%，回本只需+22.4%。

### 6.3 索普式仓位规格（可直接执行）

**输入**：权益、信号历史胜率p、盈亏比b、止损幅度s、Kelly折扣α=0.5、单笔风险上限2%、单票上限20%、总仓上限80%。
**决策顺序**：①回撤≥30%停手一周、≥20% α再砍半 → ②EV/R≤0跳过 → ③算f*取半Kelly → ④单笔风险预算=权益×2% → ⑤买入市值=风险预算/止损幅度 → ⑥取与Kelly市值、单票20%、总仓80%的较小值。

### 6.4 索普的实盘参考（他是真做出来的）

- Princeton-Newport Partners 1969–1988（19年）：毛年化约19.1%/净约15.1%，**227个盈利月vs仅3个亏损月（月胜率98.7%），最大月亏<1%，零亏损年**；同期S&P500约10.2%。
- Ridgeline Partners 1994–2002：约18%/年；统计套利组合1992–2002：毛约26%/净约20%，年化波动约6.7%。
- 对照含义：**19年年化19%的复利≈6.8倍**——慢，但零亏损年。这才是职业玩家的活法；"三年5530倍"是比赛叙事，不是可持续系统。

### 7.2 四条结论

1. **近似回测无一跑赢中证500**；最好的V3也略输沪深300。

### 7.3 重要限定（必须讲清楚）

- 这是"从公开分享提取的规则化近似"，**不是任何一位研究对象本人的真实策略**；未做参数寻优；样本池为沪深300∪中证500当前成分（784只，含幸存者偏差，结果偏乐观）。
- 榜单数字与回测**不可直接比较**：榜单是自报+可手调账本、窗口自选；回测是真实撮合（佣金万2.5双边+卖出印花税0.05%+滑点±0.2%+涨跌停+T+1）。
- 建议对冠军数字按 **0.1–0.3 折扣**看待（5530倍 ≈ 550–1660倍量级的窗口峰值），更接近其本人"两年多一千倍"的口径。

## 第8章 实战清单与复盘模板

### 8.1 开仓前 Checklist（逐项打勾）

- [ ] **EV检查**：最近≥30笔同类交易统计出 p 和 b；EV/R = p·b−q > 0 才继续（b≥2时p≥33.3%；p=40%时b≥1.5；p=70%时b≥0.43）
- [ ] **止损预定**：入场前写死止损价（建议-6%~-7%），到价无条件平仓、不补仓摊平
- [ ] **止盈按盈亏比设计**：止损−s% → 止盈目标≥b·s%（防"赚3%就跑、亏20%扛"）
- [ ] **仓位**：单笔风险≤权益2%；买入市值=(权益×2%)/止损幅度；单票≤20%、总仓≤80%留现金；样本<50笔时用1/4 Kelly
- [ ] **回撤闸门**：账户回撤≥20%仓位再砍半；≥30%停手一周复盘
- [ ] **对手盘思维**：我买，谁在卖给我？（题材挖掘/低吸的反面：我接的是谁的货）
- [ ] **本质思维**：这个现象合不合理、正不正常？（涨停基因、低位、量能是否构成真实逻辑）
- [ ] **情绪检查**：我现在是贪婪还是恐惧？上次同样情绪后来怎样？

### 8.2 复盘模板（每日/每周）

| 项目 | 内容 |
|---|---|

### 8.3 每周数据义务（索普式）

- 维护交易日志，每周更新：胜率p、平均盈利、平均亏损、盈亏比b、单笔平均风险。
- **样本<30笔不下结论**；用滚动40笔估计(p,b)并据此调仓位（回测V4就是这么做的）。
- 月底算一次：年化、最大回撤、夏普、Calmar——而不是只看"赚了多少"。

## 第9章 常见错误与误区

1. **迷信榜单**：官方榜单=自报+可手调账本；"冠军"是商业化流量赛事的排行，不是监管或交易所认可的实盘名次。先问核验三问（交割单/窗口自选/多账户）。
2. **高胜率陷阱**：胜率70%但盈亏比0.15，长期必亏（EV=−0.195）。
3. **重仓押注**：满仓一只票，连吃5个-10%需要+69.4%回本；单笔2%风险连亏10笔只需+22.4%回本。
4. **马丁格尔加仓**：跌了补仓摊平——连亏后自动放大下注，破产概率=1。
5. **把"比赛倍率"当"可持续系统"**：5530倍是窗口峰值叙事；索普19年年化19%才是职业玩家的现实。
6. **认为仓位管理能创造收益**：V4证明仓位管理只保护edge——**先确认EV>0，再谈怎么下注**。
7. **忽略成本与滑点**：小盘股滑点1%~3%常见，打板炸板一次亏5%~10%；回测假设±0.2%滑点已偏乐观。
