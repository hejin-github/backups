# 大V战绩核验方法论

> 适用：任何"操盘风云/同花顺投资账本/××杯"榜单交易大V的 X年Y倍 战绩核验。目标：严格区分「可独立查证事实」与「选手/主办方宣称」，不编造任何交易记录、榜单或截图。

## 0. 榜单性质（先记住）

官方榜单数字 = 选手自报持仓截图OCR + 可手动调整的同花顺投资账本记录；窗口自选、可多账户多段混排、无独立审计、无券商API只读同步披露。**榜单口径 ≠ 独立审计的实盘可持续收益。**

## 1. 五步核验流程

1. **收集宣称清单**：逐条列出选手/主办方/媒体说过的每个数字，记录原始出处（视频URL/文章URL）与原话。同一人多口径时必须并排列出。
2. **独立第三方检索**：地方官媒、持牌财经媒体（证券时报/中证报/上证报）、B站官方录像、现场照片、平台榜单页；区分「可证实」与「仅一方称」。检索反证（骗局/打假/质疑）也应记录。
3. **复利数学检验**：年化=倍数^(1/年数)；月化=倍数^(1/月数)−1；日化=倍数^(1/交易日数)−1。对照A股约束（±10%/±20%涨跌停、单次摩擦0.1%~0.15%、小票滑点1%~3%）。
4. **口径矛盾检查**：同一事迹多个数字时列出最大差；要求合理解释；无解释 → 记录为红旗。
5. **交割单证据分级**：券商盖章交割单 > 账本API流水 > 选手贴图（可PS）> 仅口播。检索"交割单 实盘"各平台（抖音/知乎site:/雪球/股吧/微博），**未找到必须明说"未检索到"**。

## 2. 打标规则

| 旗标 | 含义 | 示例 |
|---|---|---|
| 🟩 绿旗 | 有第三方独立来源交叉印证的事实 | 参会获奖、人物身份、比赛存在 |
| 🟨 黄旗 | 存疑但数学上非不可能 / 有本人+媒体口径但无独立流水 | 年化100%~1000%区间、无交割单 |
| 🟥 红旗 | 数学上接近不可能（日化≥1.5%连续一年+）或仅口播且口径矛盾 | 14个月722倍、无任何可核验记录 |

## 3. 核验三问（对任何"X年Y倍"）

1. 有无券商盖章交割单 / 可独立核验的逐笔流水？（没有=无法独立复核）
2. 窗口起止是否自选？（自选=可能从低谷重启或从峰值起算）
3. 同选手是否多账户/多段上榜？（多段=对外展示的是最好的一段）

## 4. 口径矛盾检查清单

- [ ] 同数字是否有多版本（颁奖口播 vs 本人PPT vs 媒体）？
- [ ] 各版本对应时间窗口是否一致？
- [ ] 主办方是否公开解释差异？（不解释 → 红旗）
- [ ] 选手本人对外是否只用较小口径？（如六个核弹007 只用17.5倍、不用722倍）

## 6. 实例速查（2026-10 研究完成）

- **钧哥_天下无双**：总榜冠军 +552976.22%（2023-01-01~2025-12-18，35.5个月）；口径四版本差221倍；无交割单。榜单黄旗 / 实盘可持续收益红旗。
- **童辰**：总榜亚军 +80890.37%（2016-06-15~2025-09-03，9.2年），年化≈106.8%、日化≈0.30%——数学可行（黄旗）；双账户择利+无交割单。
- **六个核弹007（凌国民）**：总榜季军 72233.05%（722倍）vs 本人/媒体 1750.99%（17.5倍/16个月），差41倍；722倍红旗、17.5倍黄旗。
