# 索普原理与仓位管理

> 来源：爱德华·索普《击败庄家》(Beat the Dealer, 1962/1966)、《击败市场》(Beat the Market, 1967)、《量化的赛局》(A Man for All Markets, 2017)；Kelly 1956《A New Interpretation of Information Rate》；Princeton-Newport Partners / Ridgeline Partners 实盘数据。

## 1. 核心公式

| 概念 | 公式 | 说明 |
|---|---|---|
| 期望值 EV | EV = p·b − q（q=1−p），或 EV/R = p·(1+b) − 1 | 每下注1单位风险的期望回报；**≤0 不做** |
| 盈亏平衡胜率 | p* = 1/(1+b) | b=1.5→40%；b=2→33.3%；b=3→25% |
| Kelly 仓位 | f* = (b·p − q)/b = p − q/b | 最大化对数增长率；全Kelly回撤常超50% |
| 半Kelly | f = 0.5·f* | 保留约75%增长率、波动减半；索普实务用法 |
| 回本涨幅 | 跌幅/(1−跌幅) | −50%→+100%；−90%→+900%（放弃） |
| 回撤控制 | 回撤≥20%仓位砍半；≥30%停手 | 保护净值不被爆 |

## 2. 量化反例（散户死法）

1. **高胜率死法**：胜率70%、赚3%就跑亏20%扛 → b=0.15 → EV/R=0.70×0.15−0.30 = **−0.195**。70%胜率长期每押1元亏0.195元。
2. **满仓连亏**：满仓连吃5个-10% → 0.9⁵=0.5905（回撤40.95%，回本需+69.4%）；单笔2%风险连亏10笔 → 0.98¹⁰≈0.817（回撤18.3%，回本只需+22.4%）。

## 3. 索普式仓位规格（可直接执行）

**输入**：权益E、信号历史胜率p、盈亏比b、止损幅度s（如6%）、Kelly折扣α=0.5、单笔风险上限2%、单票上限20%、总仓上限80%。

**决策顺序**：
1. 回撤闸门：账户回撤≥30% → 停手一周；≥20% → α×0.5。
2. EV 检查：EV/R = p(1+b)−1 ≤ 0 → 不开仓。
3. Kelly：f* = (b·p−q)/b；f_use = α·f*。
4. 风险预算：risk_budget = E×2%。
5. 目标市值：by_risk = risk_budget/s；by_kelly = E·f_use/s；by_single = E×20%；by_total = E×80% − 当前持仓市值。
6. 取 min(by_risk, by_kelly, by_single, by_total) 为该笔买入市值；若≤0不开仓。

**注**：样本<50笔时使用1/4 Kelly（α=0.25）；滚动估计(p,b)时给先验（如p=0.45、b=1.5）防止过拟合小样本。

## 4. 索普实盘参考（他是真做出来的）

| 基金 | 期间 | 业绩 | 备注 |
|---|---|---|---|
| Princeton-Newport Partners | 1969–1988（19年） | 毛≈19.1%/年、净≈15.1%/年；**227盈利月 vs 3亏损月（月胜率98.7%），最大月亏<1%，零亏损年** | 同期S&P500≈10.2%/年 |
| Ridgeline Partners | 1994–2002 | ≈18%/年 | 统计套利 |
| 统计套利组合 | 1992–2002 | 毛≈26%/净≈20%/年，波动≈6.7% | 无风险利差策略 |

**对照含义**：19年年化19% ≈ 累计6.8倍——慢，但零亏损年。"三年5530倍"是比赛叙事，不是可持续系统。对榜单冠军数字按0.1–0.3折扣看待更接近窗口峰值口径。

## 5. 散户缺陷 → 索普修正对照表

| 散户缺陷 | 索普修正 |
|---|---|
| 重仓押注、满仓单票 | 单笔风险≤权益2%；单票≤20%；总仓≤80% |
| 不止损、扛单 | 入场前写死止损价（-6%~-7%），到价无条件执行 |
| 盈亏比失衡（赚小亏大） | 止盈目标≥b×止损幅度；EV/R≤0不做 |
| 连亏后加倍（马丁格尔） | 仓位只随滚动(p,b)与回撤闸门变化，永不因亏损加码 |
| 高胜率幻觉 | 先算EV；胜率70%而b<0.43照样亏 |
| 忽略成本滑点 | 回测含佣金万2.5双边+印花税0.05%+滑点±0.2%；小票实盘滑点另计 |
| 迷信榜单倍率 | 核验三问（交割单/窗口自选/多账户）；复利数学检验 |
