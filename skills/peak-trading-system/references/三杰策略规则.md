# 三杰策略规则（可程序化版本 V1–V4）

> 用途：从公开分享中提取"可程序化规则"时的参考写法与已固化的回测变体。
> 原则：每条规则注明来源性质；缺失环节如实列出；回测变体 ≠ 研究对象本人的真实策略。

---

## 1. 钧哥_天下无双 → V1「绿盘低吸」

**公开体系**：不打板、不追龙头、不做超短；题材挖掘（每日复盘韭研公社/雪球/各论坛）→ 找核心板块核心个股 → 中低位低吸/半路；仓位约1/3；卖出无固定锚点；龙虎榜仅参考；第一法则=控制回撤（单月回撤十几个点）。

**规则化近似（V1）**：

| 环节 | 规则 | 来源 |
|---|---|---|
| 题材代理 | 近30日出现涨停 | 研究假设（"新题材/首波"无客观算法） |
| 买点 | 当日收跌（绿盘）、当日非涨停非跌停 | 中低位低吸→绿盘近似 |
| 仓位 | 单票≤33%，最多2只 | 本人约1/3 |
| 卖出1 | 自持仓最高点回撤-10% | 研究假设（移动止损） |
| 卖出2 | 3日不创新高且亏损 | 研究假设 |
| 卖出3 | 持仓7日到期 | 研究假设 |

**缺失（无法程序化）**：题材认知与信息筛选本身、核心板块判定、具体卖点决策、指数暴跌3点以外的情绪反应。

**回测**：累计-0.28%、年化-0.10%、最大回撤-41.3%、胜率32.9%、盈亏比2.13、夏普0.03、258笔。

**结论**：规则化后只剩"涨停后绿盘买入"的弱均值回归，反复被止损；alpha 在信息认知层，不在买点。

## 2. 童辰 → V2「冰点半路」

**公开体系**：市场冰点才出手（情绪差）、低位半路（非打板）、-4%止损、胜率46%靠盈亏比、2018年回撤62.8%。

**规则化近似（V2）**：

| 环节 | 规则 | 来源 |
|---|---|---|
| 情绪过滤 | 样本池当日涨停家数≤3（冰点代理） | 研究假设 |
| 位置 | 收盘价 ≤ 120日最低价×1.25 | 低位近似 |
| 涨停基因 | 60日内有涨停 | 研究假设 |
| 买点 | 当日涨幅∈[5%,8%) 且未涨停 | 半路近似 |
| 止损/到期 | -4%机械止损；5日到期；最多3只等权 | 本人-4%止损 |

**缺失**：冰点/情绪的权威阈值（涨停家数、连板高度、炸板率）、选股优先级、止盈规则。

**回测**：累计+6.51%、年化+2.21%、最大回撤-18.3%、胜率43.0%、盈亏比1.51、夏普0.09、93笔。

**结论**：防守型结构回撤可控，但 EV/R=0.43×1.51−0.57≈0.08 极薄，扣真实成本后几乎无超额。

## 3. 六个核弹007（凌国民/凌零柒）→ V3「小市值短线」

**公开体系**（2026-01-03 巅峰会演讲）：
- 选股（首板）：市值<100亿；股价<20元（优选<10元）；历史低位+放量突破；当日量≥前15日均量2倍（避开>5倍爆量）；1年涨停≥3次；板块当日涨停≥3家；偏好早盘封板。
- 高低切换：情绪好做连板接力（一进二/二进三/三进四、炸板回封），情绪差做首板——**情绪阈值未公开**。
- 仓位：单票5%~10%、同时≤3只、持股≤5天。
- 止损：机械-6%（最大-7%）；破5日线止损；打板未封板次日竞价止损；"低开低走"果断离场。

**规则化近似（V3）**：

| 环节 | 规则 | 来源 |
|---|---|---|
| 市值/价格 | 流通市值<100亿、股价<20元 | 本人明示 |
| 量能 | 量比∈[2,5]（当日量/前15日均量） | 本人明示2倍起，5倍上限研究假设 |
| 涨停基因 | 250日涨停≥3次 | 本人明示 |
| 买入 | 当日涨幅<9%且未涨停（半路/低吸替代打板） | 研究假设（打板无法在日线近似） |
| 止损 | -6%机械 或 破MA5 | 本人明示 |
| 到期 | 5日 | 本人明示 |
| 仓位 | 单票10%、最多3只 | 本人5%~10%上限 |

**缺失**：情绪/板块强度阈值、止盈具体点位（"+5%~+10%区间"）、低吸模式细节、翘板模式细节、"单波/两波"分时过滤（需Level-2）。

**回测**：累计+16.59%、年化+5.46%、最大回撤-6.8%、胜率38.1%、盈亏比3.06、夏普0.69、84笔。

**结论**：风险调整后最优；低胜率+高盈亏比+机械止损结构健康；但84笔样本小、小票实盘滑点可能远超回测假设。

## 4. 索普仓位变体 → V4「半Kelly」

**规则**：在 V3 信号上叠加索普式仓位管理——滚动40笔估计(p,b)（先验p=0.45、b=1.5启动）；EV/R≤0不开仓；f*=半Kelly；回撤≥20% α减半、≥30%停手；单笔风险≤权益2%；单票≤20%、总仓≤80%。

**回测**：累计-9.78%、年化-3.50%、最大回撤-9.8%、胜率10.0%、盈亏比0.44、夏普-2.49、20笔。

**结论**：弱 edge 下 EV 过滤使仓位收敛为 0、几乎不开仓——**仓位管理不创造 edge，只保护 edge**。

## 5. 统一回测约定（引擎内置）

- 区间：2023-10-09 ~ 2026-10-09（728个交易日）；样本池：沪深300∪中证500当前成分（784只，含幸存者偏差，结果偏乐观）。
- 数据：baostock 前复权日线；信号T日收盘算、T+1开盘成交；买入=开盘×(1+0.2%滑点)、卖出=开盘×(1−0.2%)；佣金万2.5双边+卖出印花税0.05%；开盘涨停不买、开盘跌停延卖；T+1。
- 指标口径：累计=(末/首−1)；年化=(末/首)^(252/n)−1；最大回撤=净值相对历史高点的最大跌幅；夏普=(日收益均值−RF/252)/日收益标准差×√252；盈亏比=平均盈利/|平均亏损|。
