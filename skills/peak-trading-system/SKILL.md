# 巅峰操盘体系（Peak Trading System）

研究大V → 核验战绩 → 提取策略 → 近似回测 → 索普仓位修正 → 教程学习与实战复盘。

## 使用前必读：诚实性红线

1. 官方榜单数字 = 选手自报持仓截图OCR + 可手动调整的同花顺投资账本记录，窗口自选、多账户择利、无独立审计。**榜单口径 ≠ 独立审计的实盘可持续收益**。
2. 未检索到券商盖章交割单时，必须明说"未检索到可核验交割单"，**禁止编造任何交易记录、榜单或截图**。
3. 从公开分享提取的策略规则写成"近似回测变体（V1–V4）"，**不得表述为研究对象本人的真实策略**；回测结果不得为榜单数字背书或证伪。
4. 对任何"X年Y倍"先做复利数学检验（年化/月化/日化复利折算）并打标：🟩绿旗（可证实）/ 🟨黄旗（存疑但非不可能）/ 🟥红旗（数学上接近不可能或无独立证据）。

## 工作流（四步）

1. **核验战绩**：按 `references/大V战绩核验方法论.md` 执行——收集宣称清单（含出处URL）、独立检索第三方证据、复利数学检验、口径矛盾检查、交割单证据分级、可信度打标。
2. **提取可程序化策略**：从公开分享（抖音演讲/知乎/雪球/媒体）提取选股、进出场、仓位、止损规则；每条注明来源；缺失环节如实列出。参考 `references/三杰策略规则.md` 的 V1–V4 规则写法。
3. **近似回测**：运行 `scripts/` 流水线（下载 → 预处理 → 回测 → 指标），时间窗口默认最近3年，基准沪深300/中证500，输出累计/年化/最大回撤/胜率/盈亏比/夏普/笔数并画净值曲线。
4. **索普仓位与改进建议**：用 `references/索普原理与仓位管理.md` 的 EV/盈亏比/Kelly 规格评估策略与给出仓位修正（默认半Kelly、单笔风险≤2%、单票≤20%、总仓≤80%）；可运行 `scripts/kelly_position.py` 计算单笔仓位。

## 教程学习

章节式系统教程在 `references/教程.md`（理论→案例→实战清单→复盘模板），适合完整学习与反复查阅；需快速查某位大V的规则时直接看 `references/三杰策略规则.md`。

## 回测约定（引擎已内置）

信号 T 日收盘计算、T+1 开盘成交；买入=开盘价×(1+滑点0.2%)，卖出=开盘价×(1−0.2%)；佣金万2.5双边、卖出印花税0.05%；开盘涨停不买、开盘跌停延卖；T+1 不可卖当日买入。策略变体定义见 `references/三杰策略规则.md`。
