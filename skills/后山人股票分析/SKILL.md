# 后山人股票分析

## 概述

本技能将博主"后山人csAJ"公开分享的A股战法（原文整理自其抖音图集末张文字总结图）固化为可执行的分析流程，用于对单只A股做**选股→买点→卖点→做T**全流程技术判断。

**核心原则：** 只守一套高胜率模式反复执行，不东学西学；不编造教程未提及的指标、阈值或规则。

## 方法论框架（四层共振）

| 层 | 信号 | 含义 |
|---|---|---|
| ① 横盘吸筹 | 换手率 5%-15%、量比放大（≥1）、筹码低位单峰密集、均线筑底 | 主力建仓完成 |
| ② 涨停开路 | 低位/震荡区突然涨停突破，或反包涨停 | 强势启动确认 |
| ③ 缩量回踩 | 涨停后缩量回调，收小阳/十字星/长下影、不创新低，落在20日均线上 | 最后一洗 |
| ④ MACD确认 | MACD绿柱缩短转红 / 金叉、KDJ-J值低位 | 买点共振 |

## 分析工作流

对任意个股按以下顺序执行：

### 1. 取数（公开接口，无需登录）
- **先确认最近有效交易日**：分析前先核对交易日历（周末、法定节假日如春节/国庆/中秋等休市）。K线缺日先查日历再下结论，**不得把节假日休市臆断为停牌或数据异常**；确认为休市日则跳过，并在输出中注明"X月X日节假日休市"。
- **实时行情**：新浪 `hq.sinajs.cn/list=sh600519`（现价/昨收/开高低/量额）
- **盘口/换手/量比**：东财 `push2.eastmoney.com/api/qt/stock/get`（f168换手、f50量比）
- **日K线**：新浪 `quotes.sina.cn` 或腾讯 `web.ifzq.gtimg.cn`，取 120 根以上用于指标计算
- 注意：批量接口有反爬限流，逐股轮询+延时；必要时禁用系统代理直连

### 2. 计算指标
- MA5/10/20/60（判断均线排列）
- MACD(5,10,3)：DIF/DEA/柱，交叉状态
- KDJ-J 值
- 量比（当日量/近5日均量）、30日振幅、换手率
- 顶背离/底背离：股价新高但MACD红柱不新高=顶背离；反之底背离

### 3. 四层共振判断
逐层判定通过/未通过，按 [references/strategy.md](references/strategy.md) 中的量化条件。

### 4. 买卖点结论
按下方"买卖点规则"给出明确信号，输出格式见"输出格式"。

## 买卖点规则（严格按教程原文）

### 买点
1. **主升浪上车（核心）**：涨停开路 → 横盘洗盘 → **缩量回踩20日线企稳**（小阳/十字星/长下影、不创新低、企稳点落在20日线上）
2. **做T买点（有底仓）**：5分K线 MACD(5,10,3) 绿柱缩短转红；或分时底背离+快线水下金叉；KDJ-J<10 更佳
3. **形态买点**：上升三法（最后大阳线突破前高确认后才追）、美人肩（B点高于A点、5/10日线不粘合、缩量盘整）、空中加油（跳空涨停后平台量能配合、价格抗跌）
4. **集合竞价辅助**：高开 +0.5%~+2% 关注承接；高开≥+2% 强势信号（需量能跟进、板块情绪配合）

### 卖点
1. **顶背离**（股价新高、MACD红柱不新高）→ 卖
2. **水上死叉**（快慢线突破水面后，水上死叉）→ 坚决卖
3. **高位量比>10 + 换手>15%**（高量比高换手=出货警报，能跑就跑）
4. **KDJ-J≥100**（做T卖出）
5. **跌破20日线且无法快速收回** → 无条件离场
6. **趋势破位**：上升趋势刺破前低LDL后反抽不创新高 → 趋势反转离场
7. **做T卖点**：分时线乖离黄色均线3个点以上无量拉升（必被拉回）；MACD红柱开始缩短、分时拐头

## 做T方法（有底仓时）

- MACD 参数调成 **5/10/3**（比默认灵敏）
- 看 5 分K线：**MACD 绿柱缩短变红** 区间节点买入
- **KDJ-J值 ≥ 100**（同时MACD红柱从最长开始变短）时卖出，相对高点T出
- 分时上升趋势中，T完一笔等回落后重复；前提：这波做T已有利润、个股估值合理

## 量价过滤（选股时）

- 换手率 **5%-15%**：<5% 死水一潭；>15% 抢筹太激烈、次日易剧烈震荡
- 低量比（<1）+ 低换手（<1%）：无人关注，暂不参与，等量比放大
- 高位 + 高量比 + 高换手 = 警报拉满

## 输出格式

对每只股票输出：

1. **实时行情**：现价/涨跌/开高低/成交额/换手率/量比
2. **技术面**：均线排列、MACD、KDJ-J、量比、振幅
3. **四层共振**：每层 通过/未通过
4. **买卖点信号**：明确列出符合的买点/卖点（只列教程规则，不臆造）
5. **一句话结论**：如"趋势偏强，J值高位不追高，回踩20日线是买点"
