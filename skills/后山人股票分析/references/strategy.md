## 一、日内做T（核心高频方法）

### 1.1 乖离与背离
- **乖离**：价格偏离均线的距离；**背离**：价格与分时量走势相反。
- **下跌乖离买点**：股价出现新低、绿色量能未出现新高时，不急着卖，股价会拉回均线附近。**买点 = MACD 绿柱变短、绿转红时。**
- **上涨乖离卖点**：分时线与均线超过 3 个点以上无量拉升，后续会被拉回均线附近。**卖点 = 分时线拐头、MACD 红柱开始变短。**
- **顶背离**：股价新高、量能没突破新高。**卖点 = MACD 最长红柱开始变短。**

### 1.2 底背离日内T案例
- 分时K线和 MACDFS 出现底背离，且 MACDFS 快线在**水下金叉慢线** → 极佳买点。
- 卖出时机：MACDFS 快慢线**突破水面，并在水上快线死叉慢线**时坚决卖出。
- 前提：这波做T已有利润；更大前提是估值合理。

### 1.3 5分钟K线 + KDJ 做T（活仓少、日内多次T）
- MACD 数值调成 **5/10/3**（更灵敏）。
- 看 5 分K线：**MACD 绿柱缩短变红**区间节点买入。
- **KDJ 的 J 值达到 100 以上**（此时 MACD 红柱也会从最长开始变短）时卖出，相对高点 T 出。
- 分时上升趋势中，T 完一笔等回落后重复。

## 二、集合竞价

- **竞价涨跌幅 =（竞价价 − 昨收价）÷ 昨收价 ×100%**，以成交量最大的那一笔价格为准。
- 高开（偏强）：竞价价 > 昨收价；平开（中性）：±0.25% 内；低开（偏弱）：竞价价 < 昨收价。
- 参考阈值：低开≥-2% 谨慎；-2%~-0.5% 注意抛压；-0.5%~+0.5% 多空平衡；+0.5%~+2% 关注承接；高开≥+2% 强势信号。
- 必须结合量能、开盘后方向、消息面、板块情绪；别只看最后1分钟防诱多/诱空。

## 三、主力吸筹识别（六维复盘）

六维联立判断：
1. **K线与均线 MA**：筑底区→拉升区→洗盘区→再拉升区。
2. **MACD(13,26,9)**：DIF/DEA、底背离、二次金叉辅助确认。
3. **盘口数据**：委托队列挂单、成交量、买卖盘口变化。
4. **换手率变化**：地量→温和放量→放量突破。
5. **筹码分布**：低位单峰密集、上方套牢盘消化、筹码集中。
6. **成交量**：温和放量、放量突破、缩量回调的量价配合。
- 仓位原则：低位大胆买、主升浪持有、缩量回调是买点。

## 四、K线形态（抓启动）

### 4.1 上升三法
- 上涨趋势中第一天大阳线 → 随后连续小实体K线（未超出首日波动范围）→ 最后一天开盘高于前收、收盘创阶段新高。
- **必须等最后大阳线突破确认才追，未确认前不追。**

### 4.2 跳空板空中加油放量平台
- 利好刺激下主力快速建仓，跳空涨停突破前期整理区；因筹码不充分，在涨停价附近震荡整理二次建仓，成交量显著放大。
- 介入关键：确认整理期量能配合 + 价格抗跌，在平台区间介入。

### 4.3 美人肩形态
- ①强庄锁仓；②B 点高于 A 点（B 低于 A 是假肩）；③盘整时 5/10 日均线不得粘合；④A、B 之间缩量盘整；⑤下方 OBV 不可相互纠缠、开口向上。

## 五、主升浪战法（一套模式反复执行）

**涨停开路 + 横盘洗盘 + 缩量回踩 + 站稳20日线：**
1. **涨停开路**：低位或震荡区突然涨停突破，甚至反包涨停，强势信号明确。
2. **横盘洗盘**：涨停后高位横盘消化获利盘。
3. **缩量回踩**：缩量回调是"最后一洗"。
4. **站稳20日线精准上车**：回调后收小阳/十字星/长下影、不再创新低；企稳点刚好落在 20 日均线上，支撑有效、洗盘结束。

## 六、指标与趋势

### 6.1 MACD 绿柱增大（看空）
- 绿柱逐步增大 = 空头力量稳步增强，继续看空信号。

### 6.2 趋势反转核心逻辑（高低点更迭）
- **上升趋势反转**：①价位测试/刺探 LDL（前低）；②走势向上回调而后创新低。
- **下降趋势反转**：①价位测试/刺探 LDH（前高）；②走势向下回调而后创新高。
- 趋势延续靠高低点不断抬升/压低；节奏被打破就是反转。

## 七、量价与选股筛选

### 7.1 量比 + 换手率组合
- **高量比 + 高换手**（量比>10、换手15%-20%+）：若股价已涨不少，很可能是庄家最后一拨甩货。**高位+高量比+高换手=警报拉满，能跑就跑。**
- **低量比 + 低换手**（量比<1、换手<1%）：无人关注的"透明人"，暂不参与，等量比放大。

### 7.2 换手率过滤（选股八步）
- 留下 **换手率 5%-15%**：<5% 死水一潭；>15% 抢筹太激烈、次日易剧烈震荡；5%-15% 是短线资金喜欢的节奏。

## 九、交易日历与K线缺口判定

- 分析前先核对最近有效交易日：周末、法定节假日（元旦/春节/清明/劳动节/端午/中秋/国庆）休市，休市日无K线属正常。
