## 核心原则（野人原话，出自情绪周期 md）

1. 情绪周期是短线交易的核心框架，先判断阶段再定动作。
2. 赚钱效应好的时候多做，亏钱效应明显的时候少做或不做。
3. 行情生于分歧，死于加速；情绪一直看多、一直往高走时就是要注意风险。
4. 情绪的本质是人性；恐慌一旦出来很难收回来。
5. 做自己看得懂的交易：看得懂就做，看不懂就别做；高位追高跟自己没关系。
6. 资金永远超前于消息：先动的是资金，后到的是消息；等散户听到消息时已经晚了，能给你上车的位置往往就是高位。
7. 不要去预测，跟着盘面变化随机应变。
8. 空仓是一种智慧；退潮期、冰点期不能重仓、不能乱切核心，那个时候杀的就是核心。
9. 不要用第二笔去为第一笔的错误买单（不补仓摊平错误单）。
10. 龙头多条命：不要盼着龙头死；龙头一旦大面，亏钱效应比龙头活着的时候更大。
11. 高位情绪龙死了，低位不一定马上有机会，中间会有一段失落（失锁）的时间和空间。
12. 减少出手频率，只做确定性交易；短线本质是概率的游戏。
13. 慢就是快；前排买不进就宁可等轮动，绝不追高后排。
14. 低位有逻辑、有业绩支撑的波段票，在情绪规律没破时，情绪恐慌反而是低吸机会；垃圾股、没业绩的票不碰。

## 情绪周期七阶段速查

| 阶段 | 特征 | 动作 |
|---|---|---|
| 冰点 | 情绪+指数双杀、跌停最多、极致抱团 | 空仓等修复 |
| 弱修复 | 破冰股出现、连板高度回抬、亏钱效应减弱 | 没有介入点，等强修复 |
| 主升 | 龙头打出空间、板块联动、资金维护龙头 | 第一次介入点：板块启动当日上车 |
| 发酵 | 一股力量把大票全拉高、普涨 | 第二天大概率无人接力，谨慎 |
| 高潮/加速 | 跟风扩散、普涨涨停、一致看多 | 高抛减仓，不追 |
| 混沌 | 无主线、电风扇轮动、题材一日游 | 空仓或极小仓试错新方向 |
| 退潮 | 龙头大面（地板开/大单砸）、高度被压 | 空仓，三到四天后等新题材分歧弱转强再试错 |

## 判断情绪的四个要素

1. 涨跌家数 + 成交量：普涨放量 = 情绪好；普跌缩量 = 减仓空仓。
2. 昨日打板资金今日有没有溢价：有溢价 = 做多情绪高；看修复力。
3. 主线/板块延续性：一个题材能连涨三天 = 主线；有主线做主线，没主线空仓。
4. 预期管理：符合预期持股、不符合预期止损、超预期加仓。

## 进场点（按优先级）

1. 板块启动当日（主升期第一次介入点）。
2. 弱转强：板块经历一次大分歧后第二天弱转强（第二次介入点）。
3. 分歧转一致：题材第一次大分歧时上车，不是分歧当天。
4. 龙头低吸：龙头主升后回踩 20% 左右、出现三个阴线后低吸，涨停就跑或双头跑。
5. 试错：退潮三到四天后新题材出现分歧弱转强，用 10% 仓位试错。

## 离场点

- 锁仓：看懂龙头就持仓不动，不怕吃地板。
- 弱转强下车：选择下车就不要后悔后面成妖。
- 天地板：打板时极端见顶信号。
- 龙头大面（地板开/大单砸）：所有板块进入退潮，空仓。
- 高位放量 / 换手率 50%-60%：出货。
- 逻辑破位：买入依据被打破，立刻止损。
- 预期落地：业绩/事件兑现时按预设卖出。

## 仓位规则

- 没有确定性：总仓位 ≤ 10% 试错。
- 确定性出现（模式内大确定性）才加仓；第二天竞价弱转强成立、反包确认时加。
- 不满仓单吊一只票。
- 退潮期/冰点期：空仓或极小仓位。
- 不要借杠杆。

## 六段式复盘（盘后固定流程）

1. **市场环境**：指数涨跌、两市量能、涨跌家数/跌停家数、主线板块资金流向 → 定情绪阶段。
2. **持仓复盘**：当前仓位几成、持仓票今日表现、今日买卖动作是否符合模式。
3. **候选筛选**：明日观察池，列买入信号清单（启动日/弱转强/分歧转一致/龙头低吸/试错点）与风险信号清单（天地板/放量换手 50-60%/龙头大面/逻辑破位）。
4. **明日预案**：关键位；符合预期怎么办、不符合预期止损、超预期加仓。
5. **纪律检查**（野人原话）：① 第二天走势不及预期立刻离场，这叫执行纪律；② 不要用第二笔为第一笔的错误买单，不补仓摊平；③ 不加杠杆、不加大本金，仓位小就没有恐惧；④ 盈利了及时提一部分出来，克服贪婪；⑤ 不要听消息炒股，散户消息永远慢半拍；⑥ 空仓后不要因为一个冲高回落就冲进去，等确定性出现。
6. **盘感归档**：今日现象归入吸筹/洗盘/出货/情绪退潮哪一类；回头验证昨日预判的情绪滞后点对不对。
