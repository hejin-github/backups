# 全能的野人 · 情绪周期

> 本文由野人 87 个情绪周期相关视频的语音转写整理而成。只做纠错、去口水、去重、理顺语序、统一术语；野人没说过的数字、阈值、仓位比例一律不补。

## 一、核心原则

1. 情绪周期是短线交易的核心框架，理解市场当下处于哪个情绪阶段，才能制定正确的交易策略。
2. 核心心法：赚钱效应好的时候多做，亏钱效应明显的时候少做或不做。
3. 行情生于分歧，死于加速：一波情绪在分歧中诞生，在一致、加速、一致看多中见顶；情绪一直看多、一直往高走的时候，就是要注意风险的时候。
4. 情绪的本质是人性；恐慌情绪一旦出来，很难收回来。
5. 做自己看得懂的交易：看得懂就做，看不懂就别做；非要在高位追高，跟自己没关系。
6. 资金永远超前于消息：先动的是资金，后到的是消息；等散户听到消息时已经晚了，能给你上车的位置往往就是高位。
7. 不要去预测，跟着盘面变化随机应变。
8. 空仓是一种智慧；退潮期、冰点期不能重仓、不能乱切核心，因为那个时候杀的就是核心。
9. 不要用第二笔去为第一笔的错误买单（不补仓摊平错误单）。
10. 龙头多条命：不要盼着龙头死；龙头一旦大面，亏钱效应比龙头活着的时候更大。
11. 高位情绪龙死了，低位不一定马上有机会，中间会有一段失落（失锁）的时间和空间。
12. 减少出手频率，只做确定性交易；短线本质是概率的游戏。
13. 慢就是快；前排买不进就宁可等轮动，绝不追高后排。
14. 低位有逻辑、有业绩支撑的波段票，在情绪规律没破时，情绪恐慌反而是低吸机会；垃圾股、没业绩的票不碰。

## 二、情绪周期阶段划分与特征

野人在复盘里反复使用的阶段词：冰点 → 冰点修复（弱修复）→ 启动/主升 → 发酵/一致 → 高潮/加速 → 混沌 → 退潮 → 再回冰点。

### 2.1 冰点期
- 特征：情绪和指数双杀，市场温度到极致低温；跌停家数最多，亏钱效应极致释放。
- 野人原话：冰点，顾名思义就是你的情绪、或者市场的温度已经到了极致的低温；冰点的条件就是情绪和指数双杀。
- 极端形态：极致抱团——大家一致认为市场没救了、没到底，就抱在一起暴弹出来。
- 次日规律：冰点之后第二天一般接修复（弱修复），也可能继续走冰点、接分歧。

### 2.2 冰点修复 / 弱修复
- 特征：出现破冰股、连板高度开始回抬，亏钱效应减弱。
- 关键：弱修复期没有确定性——你不知道它能不能修复起来，所以这个阶段没有介入点。
- 只有修复之后、尤其是强修复（前排龙头走大阳、重新打高度）的时候，才出现介入点。

### 2.3 启动 / 主升期
- 特征：龙头打出空间，板块联动明显，全市场资金都来维护龙头、一起把短线空间打出来（野人叫"情绪主升期"）。
- 这个阶段龙头只要高举高打，短线就迎来高光时刻。
- 第一次介入点：板块向上启动的当日（上车当日）。

### 2.4 发酵 / 情绪一致
- 特征：一股力量一下把所有大票拉高、普涨，这种叫"情绪一致"。
- 情绪一致的第二天，大概率是无人接力的——因为一致之后没有新增接力资金。

### 2.5 高潮 / 加速期
- 特征：跟风全面扩散、普涨涨停，情绪一致看多。
- 规律：死于加速。一致性下杀往往会触发量化的被动机制，造成急跌。
- 操作：这个阶段要高抛、减仓，不追。

### 2.6 混沌期
- 特征：无明确主线，轮动加快，题材一日游（野人叫"电风扇轮动"）。
- 资金都在场外等着老龙头倒下，再开新周期；混沌期比较难做，尤其在理解力不够的时候。
- 操作：空仓或极小仓位试错新方向；有主线做主线，没主线就空仓跟随。

### 2.7 退潮期
- 特征：龙头大面（地板开、大单砸），连板高度被压制，跟风股先调整。
- 高度为什么被压制：纯粹做龙头的资金被深套在龙头里出不来，市场最活跃的那部分接力资金没了；各股往上走需要龙头选手、最猛的资金来接力，他们都被套住了，就没人接力，自然断板；断板之后抛压往下压，活钱全部被锁死在里面动不了。
- 流动性枯竭：各种题材往上拉的时候没有人来接力；资金被按在高位、按在地板里出不来。
- 操作：刀枪入库、马放南山，把场子交给别人做；空仓或极小仓位。

## 三、各阶段操作规则

### 3.1 判断情绪的四个要素（情绪和盘感）
野人明确说情绪非常有用，因为情绪就代表赚钱效应。判断方法：

1. **看涨跌家数 + 成交量**：市场普涨、成交量放大、有赚钱效应，就是情绪好；成交量缩小、市场普跌、亏钱效应释放，这个时候作为高手就应该减仓或空仓。
2. **看昨日打板资金今日有没有溢价**：昨天打板的资金今天给溢价，说明做多情绪高，短线资金还会继续进攻；再看昨天打板的修复力——有没有人今天愿意来解放昨天被套的做多资金。流动性好的时候，全市场都是活跃的做多资金，市场就好。
3. **看主线 / 板块延续性**：一个题材能延续三天持续走强，说明参与的人多、是主线；有主线就放量做主线、做连板；没有主线就空仓跟随。
4. **做预期管理**：所有交易策略都建立在预期上——盘面符合预期就持股，不符合预期就止损，超预期就加仓。这就是系统和模式，有了它就不会被自己的情绪化交易带着走。

### 3.2 龙头的三种走势与应对（主升期第二天怎么看龙头）
短线第二天什么都不用看，就看龙头。龙头三种走法：

1. **龙头高开高走、破局，成为新的市场情绪总龙头**：之后不要碰中位股，只做龙头或者低位股；从这天起才有"中位股"的概念。
2. **龙头断板，但没有出现大面**：围绕龙头去做跟风和补涨；补涨没有确定性，需要拼一点点盘感。
3. **龙头断板，或者出现大面**：短线客就要开始刀枪入库、马放南山——龙头一旦大面，就进入下一个周期环节，也就是混沌期或者退潮期。

> 为什么叫"合理"：第二天全市场做短线的资金都会去维护龙头、把短线空间打出来，因为所有板块的资金都不希望龙头断——龙头断会带崩其他板块进入退潮。这就是"龙头多条命"的原因。

### 3.3 题材突然爆发的三个介入点
当一个提前看好的题材突然爆发时，怎么处理：

1. **有先手、低吸的人**：动作叫"去弱留强"——把弱的割掉、去拿强的；因为有先手，就算回撤也不怕。不要因为怕把利润搞没了，就不敢把弱的割掉去找强的。
2. **没有先手、也没提前信的人**：送一句话——要信早信，要么就别信。
3. **完全没参与上的人**：等这个题材第一次出现大分歧的时候，做它"分歧转一致"的那个点。
4. 这三个点错过之后，后面的行情就跟你无关了。这种突发上涨（量化行为）不一定有延续性，也许是某个我们不知道的消息刺激，散户的信息往往盘后才出来。

### 3.4 被买（炸板 / 被套）后，第二天怎么处理
切到一个情绪票、核心龙头之后，第二天因为情绪或利空被买了，怎么办：

- **高开，且高开符合预期或超预期**：一定要格局、拿满，不要因为上下震荡一下就跑；这个时候不会出现减仓动作。
- **低开**：低开属于预期之内，是震荡洗盘；一般会有修复动作——低开高走、或者全天震荡、或者拉到水上翻红，最次也要在尾盘做一个翻红动作。
- **全天都在水下、只在尾盘修复一点点**：这是无效修复，第二天大概率还要再修复一天。
- **逻辑**：大部分散户低开的时候习惯加一笔仓（交易习惯改不了）；还有一小部分没加仓是因为有持仓成本顾虑。所以主力要在尾盘做修复动作，把做 T 的人在尾盘洗出去。

### 3.5 仓位与禁忌
- 退潮期、冰点期：空仓或极小仓位试错；不要重仓、不要乱切核心（那时杀的就是核心）。
- 情绪不好的时候要减仓或空仓，因为你的胜率会变小，这是本质原因。
- 看不懂的时候应该止损离场，不应该被架在上面；做交易应该是独立的，不要被很多加速和计版带着走，那会让操作变形。
- 不能因为第一笔错了，就用第二笔去补它、为第一笔错误买单。
- 垃圾股、没有业绩的票不碰；做波段/趋势的票，逻辑没破、业绩符合预期时，情绪恐慌才是低吸机会。
- 高位热门题材被按在里面之后，短期修复概率低，不要盲目去接；等它回到合理价格、有性价比了，资金才会回来。
- 资金高切低时，只切核心、切抱团；"死在核心里、死在龙头里"，但不要去玩杂毛。

## 四、转强信号与退潮信号

### 4.1 转强信号
- 最高板出现"分歧转一致"：比如昨天还是冰点、跌停家数最多，第二天最高板走成分歧转一致，就是情绪有所转好（但大环境可能还不行）。
- 弱修复之后接强修复：前排龙头走大阳、重新打高度，才是真正的转强确认。
- 弱转强：板块经历一次大分歧之后，第二天弱转强，这是第二次介入点（第一次是板块启动当日）。
- 分歧时去弱留强。
- 反人性信号：散户情绪极致低迷、都不想玩了、都想从短线转去做波段/趋势，从人性角度看往往是反转的信号（情绪就是反人性的）。
- 周末从不炒股的人开始问股票、消息面发酵不大，是观察信号；美联储降息这类事件如果市场分歧大（持股的看多、空仓的看空想捡便宜），反而是好事——行情生于分歧。
- 恐慌盘释放出来之后，丢掉筹码的人第二天往往要追高补回来，次日容易有向上修复。

### 4.2 退潮信号
- 龙头出现大面：地板开、或者大单砸，这是非常大的情绪亏钱效应，会带动所有板块和题材进入萎靡。
- 高度被压制：龙头选手的资金被深套在龙头里，没有接力资金，断板、抛压下行。
- 流动性枯竭：题材拉升时没人接力；资金被按在高位、按在地板里出不来。
- 一致性下杀（往往触发量化被动机制）；但当天如果恐慌盘没有释放出来，说明情绪还没到位。
- 赚钱效应最强的板块开始出现冲高回落、套人。
- 高位股融资余额到历史极值，往往是爆仓的前兆信号。

## 五、案例 / 盘面要点（按视频日期）

> 仅保留野人明确表达过的盘面判断，作为规则的落地案例；具体个股不展开。

- **4月19日 复盘明天预期**：短线第二天就看龙头，讲龙头三种走势应对；所有板块资金都会维护龙头打出短线空间（情绪主升期），龙头断板就带崩板块进退潮。
- **4月21日 中午**：龙头属性一旦出现大面（地板开/大单砸），就是非常大的情绪亏钱效应，带动所有板块萎靡；龙头死了，其他票反包比龙头更难（龙头反弹时量比其他票大）。看下午龙头反包：反包成功、赚钱效应继续，则情绪修复；反包不成功、第二天还没有，就进入退潮，刀枪入库。
- **4月22日 闲聊预期**：上午缩量、中午后放量，是因为龙头封单巨大；但同时前两天赚钱效应好的板块开始冲高回落套人——虽然指数有修复，但判断情绪已经开始退潮。
- **4月23日 加更（情绪退潮为什么高度被压制）**：详细讲退潮期高度被压制的原理——龙头资金被套、接力资金消失、断板抛压；退潮期只玩一点点、控制回撤，出现机会再把仓位推上去。空仓、加仓、退潮、锁仓跟情绪周期是一个完整循环。
- **4月28日 闲聊预期**：昨天是冰点、跌停家数最多，第二天还五十多家，但今天最高板走成分歧转一致，情绪有所转好，只是大环境还不行。
- **5月8日 这个月预期**：看不懂的题材（看似强、进去就被埋）不做；消费电子、机器人、汽车零部件是资金高切低的行为；没有只涨不跌的股，平常心。
- **5月18日 闲聊预期**：大盘分时上蹿下跳像小盘股，是典型的洗盘表现（洗一直不建议的散户、洗技术派）；做交易不要去看技术指标，看了会有延迟、上车就是追高。"生于分歧、死于加速"。
- **6月10日 闲聊预期**：昨天是缩量修复，发现不对就提前跑了；判断情绪拐点会出现在周五，明天还是回调或弱修复预期，做好挨打准备。
- **8月29日 周五**：什么是情绪一致——一股力量一下把大票全拉高；情绪一致第二天大概率无人接力。市场不好的时候，情绪票反而容易走出抱团（暴弹）效应。
- **9月5日 下午**：什么是执行可以——心里有预期（周五有拐点），当天盘面跟预期一致时，行动要跟上、直接上车；很多人看到机会却因为心里一堆想法否定自己，下不了手。强修复之后周一走分歧，分歧时就减仓或下车。
- **9月22日 晚上**：指数鸿盘震荡时进入电风扇轮动；操作上"分歧切核心、弱切抱团"，死在核心/龙头里，但不要玩杂毛；退潮期、冰点期不能重仓、不能切核心，因为那时杀的就是核心。
- **9月26日 中午**：上周冰点、周一修复、周二冰点、周三修复、今天又冰点，毫无逻辑——可能资金害怕被监管；情绪票不可能被 A 杀。情绪修复不起来，后面不确定性多。
- **9月29日 干货**：被买后第二天的处理（高开格局、低开等修复、尾盘修复无效）；讲散户低开加仓的人性博弈。
- **10月5日 中午（情绪和盘感）**：判断情绪四要素——涨跌家数+成交量、昨日打板溢价、主线延续性、预期管理。
- **10月11日 晚**：周五外围大跌，先从人性角度分析——持股的人一片唱多、空仓的人想捡便宜；周五是强分歧，周一肯定是分歧延续；周一预期是恐慌+分歧跑不掉，但不必慌，做好自己的衣服三面地，分歧切核心。
- **10月25日 台湾同胞来大A要学什么**：从发电、光伏、工业母机、人工智能、CPU/PCB、国产替代、光模块，到看财务报表，再到 KDJ、MACD，最后才轮到学情绪周期；你的票是在前排、中位还是中军，怎么做龙头、补涨、跟风、高低切，这些都要会。这是概率的游戏。
- **11月17日 晚上**：龙头被关小黑屋（停牌核查）后，底下的杂毛不会再被龙头的涨跌带着走，会自己走加速；但这种杂毛没有确定性，游资和量化这个阶段都不玩，里面全是散户互相玩。
- **12月3日 晚上**：一致性下杀触发量化被动机制；指数没恐慌盘释放说明情绪还没到位；这个阶段应该轻仓或空仓去玩、不要谈行情。商业航天第二天大分歧时，上车点是分歧转一致，不是分歧当天。
- **12月11日 下午收盘**：什么是交易系统——昨晚预期今天是修复，开盘后盘面没有修复意愿，盘感告诉自己要减仓；冲高清仓后盘面把人逼得没办法；到这个位置就是冰点了，冰点应该套利，尾盘又全部杀进去博第二天。
