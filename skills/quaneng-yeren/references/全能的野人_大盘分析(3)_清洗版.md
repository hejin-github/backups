## 一、核心原则

1. **正道行情就是快速轮动、没有主线**：指数看着不错，但板块轮动极快，今天明天可能切算力、也可能切回老题材，没人知道明天轮动哪个；看不懂就不做，或者只切核心、切抱团。
2. **分歧的时候切核心，弱势的时候切抱团**：这是博主反复强调的两句话，是行情轮动期的总操作纲领。
3. **保住本金是第一位**：当下行情不具备自己的交易模式时就空仓/控仓，不要硬做；在市场里看不懂还在场内，早晚把钱亏回去。
4. **做股票做到最后都是人性的博弈**：都想冲高跑，谁来拉？满仓等别人来救是不可能的，只能自救。
5. **慢就是快**：别人大亏时你小亏或小赚，别人大赚时你跟着赚，长期这么做就是拉开差距的地方；市场比的不是一天赚多少，而是比一年、两年、三年谁活得久。
6. **永远留后路、留子弹**：不可能所有风险都可控，必须有一部分资金放在外面；等机会来的时候没有子弹、风险来的时候出不来，就只能硬扛。
7. **指数是指数，情绪是情绪**：指数新高不代表赚钱效应好；要区分指数行情和个股情绪。
8. **不迷信技术指标**：指标是滞后的、有欺骗性的；靠指标在这个市场不可能稳定赚钱，量化指标也就百分之几的胜率。
9. **不做 T**：做 T 看似降成本，实则容易卖飞主升、补错下跌段；做 T 只能用于解套，不能让成本真的降下来。
10. **题材延续性要靠盘面验证**：看首板数量、梯队完整度、龙头封单、中军表现，不要听消息炒股。
11. **高位走一字、走加速就是见顶信号**："龙头死于加速"，高低位只要走加速都尽量不参与，吃加速段都没有好下场。
12. **大盘点位与仓位**：3000 点附近回来时没有确定性，不敢重仓；大盘站上 3500 才敢加仓。
13. **交易必须有自己的模式**：学技术、学逻辑、学思维，结合自己的能力在实战中跑出自己的交易模式，不能照抄博主的票。

## 二、术语与定义

- **正道行情**：指数没有大风险，但板块快速轮动、无持续主线的行情。
- **分歧 / 弱转强 / 转一致**：题材内部资金产生分歧；分歧后重新走强为弱转强；分歧转一致是上车信号。
- **抱团 / 切抱团**：弱势时资金集中抱少数核心票。
- **核心 / 情绪龙 / 板块龙头 / 市场总龙**：情绪走到最后已脱离板块和指数，本身就代表市场赚钱效应和高度；情绪龙好则市场赚钱，情绪龙差则市场亏钱。
- **中军**：题材里的大市值权重股，像航母，掉头慢；中军一直强，题材第二天大概率有延续性。
- **首板 / 连板 / 一字板 / 上板 / 打板 / 换手板**：涨停相关术语。
- **加速**：高位连续高开高走、一字板；博主视为见顶信号。
- **缩量上涨 / 缩量下跌 / 多杀多**：缩量下跌是因为没有新买盘，套牢盘和早盘跑掉的两波人互相杀跌。
- **赚钱效应 / 亏钱效应**：场内散户账户是普遍盈利还是普遍亏损。
- **退潮期 / 混冷期（混沌期）**：退潮期情绪退潮；混冷期没有主线，只有少数题材能动。
- **低吸 / 加仓 / 减仓 / 控仓 / 锁仓**：仓位操作。
- **洗盘 / 出货 / 吸筹**：庄家行为。高位放量滞涨要么出货要么吸筹。
- **大屁股**：大市值票。
- **大小票切换**：风险逐步从大票向中小市值切；中市值约 100–500 亿，小市值约 50–110 亿。
- **自治理 / 执行力**：打赚的时候要离场、打亏的时候要进场、管住手。

## 三、操作规则

### 3.1 分歧 / 弱势期的总开关
- 触发条件：大盘进入正道轮动、无主线、混沌期。
- 动作：分歧时切核心，弱势时切抱团；看不懂就空仓，或只做自己看得懂的一两个票。
- 禁区：到处追热点、今天追进去明天跌一点就跑，这种做法在混沌期必亏。

### 3.2 题材延续性判断（四要点）
- 触发条件：新题材出现当天。
- 动作：依次看——① 当天首板数量；② 题材梯队是否完整；③ 龙头封单够不够大；④ 中军有没有高开低走。
- 细则：中军像航母，掉头慢，中军一直强，第二天大概率有延续性；题材爆发第二天大概率分歧，分歧时看断板多少、中军还强不强、大单一字封高度。
- 禁区：不要听消息炒股；消息出来之前资金洗盘要洗半个月到一个月，散户消息永远慢半拍。

### 3.3 高位加速票回避
- 触发条件：票在高位，走高开高走、T 字板、一字板加速。
- 动作：尽量不参与。
- 理由：高位 99% 是见顶信号，即"龙头死于加速"；里面的人赚了 30%，外面的人见不得你好，不会来抬轿。
- 低位例外：低位走加速要看是世界性驱动还是主导经济驱动，有本质区别，但无论高低位，走一字加速都不参与。

### 3.4 仓位与后路
- 触发条件：任何时候。
- 动作：永远留一部分子弹在场外；大盘 3000 点附近不加仓，站上 3500 才敢加；看不懂就控仓。
- 禁区：满仓一只票、把全部身家押进去等别人来救。

### 3.5 不做 T
- 触发条件：想日内做 T 降成本。
- 动作：不做。
- 理由：① 你无法保证每次买在最低卖在最高，做 T 就是猜；② 尾盘跳水，T 出去的部分没接回，第二天一个大面就回去了；③ 主升前重仓躺了很久，做 T 做剩 1/3–1/4 仓，再也追不上；④ 下降段早上买一笔，眼睁睁从半仓变满仓，第二天只能割或躺。做 T 只能用于解套，不能真正降成本。

### 3.6 大盘回调与修复
- 触发条件：指数如期回调。
- 动作：良性回调不用恐慌；可以做高低切，也可以选择格局。
- 细则：如果修复是靠石油、银行、保险这些大权重拉的，而科技/主线没动，这种修复是无效修复，情绪还要延续分歧。

### 3.7 情绪龙 / 核心的持有
- 触发条件：手上有核心、情绪龙、板块龙头、市场总龙。
- 动作：大盘不好反而是短线选手的春天，这些核心票反而可能逆势表现；拿着不要动，不要频繁调仓换股。
- 理由：市场短线效应差时，资金会抱团找入口点打短线效应，包括连板高度。

### 题材怎么才有延续性
今天专门讲题材延续性怎么判断。
第一个，爆发当天的首板数量；第二个，梯队完不完整；第三个，龙头的封单够不够大；第四个，今天中军的表现有没有高开低走。
如果中军一直表现很强，大概率第二天有延续性。因为中军好比一艘航母，它上传、下传、掉头比小船更难，掉头要花很大时间，大概率不会把人直接甩下来；你亏它、你涨它，都是比较慢慢地上或者慢慢地下。一个题材的延续性通过这几天去判断。
第二，题材爆发当天之后，第二天大概率出现分歧。分歧的时候要看断板多少、中军还够不够强势、反馈够不够、大单一字封高度。这是第二天去看的。
