# 全能的野人 · 宏观经济


## 一、核心原则

1. 大周期看宏观，小周期看情绪；宏观环境决定市场大方向。
2. 不要听消息炒股；消息也分等级，字越大事越大，级别越高事越大。
3. 我们只看资金量；资金是提前知道消息的。
4. 重要的不是美联储加不加息本身，而是降息预期在不在；有预期就有想象空间。
5. 预期博弈：利好落地即利空，利空落地即利好；提前埋伏、落地兑现。
6. 我们现在是独立行情，有自己的周期和筹码博弈，不需要看老美脸色。
7. 经济数据（CPI）符合预期时，顺周期、大宗商品会先显现出来——这就是资金和散户的信息差。

## 二、术语与定义

预期博弈：在事件落地前埋伏，落地时兑现，而不是落地后再追。
利好落地即利空：大家预期的利好真出时，就是主力兑现时。
利空落地即利好：大家害怕的利空真出时，反而是买点。
信息差：资金提前知道数据/消息，散户看到时已经晚了。
顺周期：与宏观经济同向波动的板块，如煤炭、消费、旅游。
猪周期：猪肉价格的周期性波动；供大于求时猪价跌，但板块个股会提前炒预期。
降息预期：未来是否降息的可能性；比是否真的降息更重要。

## 三、操作规则


### 3.1 美联储议息的预期博弈

事件前：判断加息/不加息的概率；如果不加息概率极高，就在议息会议公布前低吸。
事件落地：公布不加息（利好落地）时兑现止盈；公布后等一个回踩再看。
会前观察：在加息之前你要看它涨还是不涨——涨我就提前走，不涨我就等落地再走。
本质：这就是预期和利好落地即利空、利空落地即利好，提前兑现。

### 3.2 怎么读消息/会议

看字的大小：咱们中国人办事，字越大事越大；比如阅兵说的"不覆盖全球精准打击"这八个字，字越大事越大。
看参会级别：这次会议全是老大去，就证明这个会议非常重要，并且会发布对经济和资本市场重要的规划和消息。
看降息预期：老美降息之后我们要不要跟着降息不重要；重要的是未来（年底或什么时候）我们有降息这个预期在这里，那就是对资本市场有无限的想象空间。
一句话：不要听消息炒股，我们只看资金量。

### 3.3 CPI数据解读框架

CPI符合预期说明居民消费回来了，老百姓更愿意花钱了。
底层逻辑：一是节日（国庆/中秋）刺激的消费；二是国家通过补贴方式刺激消费（如家电以旧换新、消费电子）。
找结构：看分项里哪个跌得多——比如猪肉跌得多，说明猪周期下半年供大于求；这就是为什么这两天猪周期板块个股上涨，因为资金提前知道这些数据。
货币政策推论：市场恢复活力了，降准降息的预期就会下降；不需要很宽的政策去调节，让市场自由发展。
资金去向：大宗商品、有长线逻辑的、顺周期的煤炭，会先在这里显现出来——这就是资金和散户的信息差。

### 3.4 日本加息的大国博弈解读

时间节点：日本加息的时间节点和老美降息的时间节点刚好卡住。
日本为什么这时加息：日本国内通胀已经到了节点；它在前面替老美冲锋，换取老美在军费、武器制造、金融支持上的实质利好。
老美放钱逻辑：老美要向外面放钱，但不想流入不喜欢的国家，想流入自己左手换右手；日本就是它的后援。
提前布局：巴菲特和美国投行早在一年前就已经入股日本五大商社，为日元加息后日本经济回流时吃这一盘。
对我们影响：肯定有影响——资本逐利，美元、日元和日本本土资金回流日本时，投资客会蜂拥而上；明年就是一个金融博弈的年份。
应对：我们国家肯定有很多应对政策，我们稳定。
