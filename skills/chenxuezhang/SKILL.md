## 适用场景

- **风格**：纯资金驱动型超短线（博主自称"纯资金驱动型交易"），不做中长线、不做价值投资、不格局。
- **主攻模式**：**断板反包**（吸筹→异动首板→洗盘大阴→护盘→反包大阳），辅以**分层低吸**、**日内做 T**。
- **票池**：主板、流通市值约 30–50 亿最佳（公式在 150 亿以下最准）、股性活跃、处主线题材。
- **典型持仓周期**：1–3 天，"今天抓明天放，最多 3 天"；反包成功后"6 个点够了就走，不跟票谈恋爱"。
- **不适用**：单边大熊、情绪混沌期无主线、流通市值 >150 亿的大盘股、2–3 元低价量化老庄股、心电图式死股。

## 术语表（全文统一口径）

| 术语 | 本文档含义 |
|---|---|
| **断板** | 首板涨停后次日未能连板，收出大阴线（或跳空缺口被回补）。 |
| **反包** | 断板洗盘后，再出一根大阳线把前一根大阴实体吞掉，重新启动。 |
| **断板反包四步** | 吸筹（底部横盘温和放量/急跌缩量）→ 异动（缩量首板，最好跳空）→ 洗盘（放量大阴，砸到首板开盘价/缺口）→ 护盘（小阴小阳缩量守住支撑）→ 反包（放量大阳吞阴）。 |
| **承接** | 下跌或回调时，下方有真金白银主动买入接住抛压，盘口表现为大压单被吃掉而非撤单、明细出现主动买盘。 |
| **分歧 / 一致** | 多空看法不一致叫分歧（此时量增价平或冲高回落）；看法一致叫一致（同向放量涨停/跌停）。分歧转一致是买点；一致转分歧是卖点。 |
| **顶背离** | 价格创新高，但 MACD 不创新高 **且** 成交量缩到前一波一半或 1/3 以内 → 当日 S 点。 |
| **底背离** | 价格创新低，但 MACD 不创新低 **且** 持续缩量（地量）→ 当日 B 点。 |
| **量价背离** | 价格破新高但成交额/额线不破新高（缩量拉升），汽车没油跑不远。 |
| **有效放量** | 首次拉升时，当根红色 K 线对应成交额 ≥ 流通市值 0.5%。 |
| **上板量** | 首板涨停所需成交额 ≈ 流通市值 1%；断板反包板需 1.5%–2%。 |
| **做 T** | 持仓底仓不动，日内冲高减仓、回落接回（或反之），目的是降低成本，不是非要做。 |
| **加权平均线** | 分时黄线 = 当日所有买入者平均成本；价格在其上打架=强势，在其下=弱势。 |
| **护盘位** | 首板开盘价（实体板）或跳空缺口（跳空板）；下方叠加 5/10/20 日均线。破且不回=洗盘变砸盘。 |
| **250 日线** | 年线，牛熊分界线；跳空站上年线=主力明牌转多的态度。 |
| **龙头/大哥** | 主线板块里涨速最快、涨幅最高、人气最旺、能独立扛压的将军。 |
| **老二/元帅** | 中军，体量大、涨幅不最高但稳住板块信心。 |
| **跟风/小兵** | 气氛组，龙头冲它跟、龙头撤它比谁跑得快。 |
| **篡位者** | 龙头老了之后，新冒出来想取代它的票。 |
| **鳄鱼原则** | 鳄鱼咬住脚时，必须在它咬到整条腿之前斩断脚——破位必走，不幻想。 |
| **盈亏不对称** | 用小止损（小代价）博大盈利，以保护本金/收益为第一目标。 |
| **缩量看共识，放量看分歧** | 成交量底层核心口诀：没量=大家观点暂时统一；放量=两拨人对倒交换货物。放量≠有人进场，关键看谁在主动拿货、谁在甩货。来源：7670123187519574643。 |
| **有量没额（虚承接）** | 价格大跌、量放大但成交额没变=场内存量筹码在低位互道、刷手数；常见长下影。真反转必须增量资金同步放大成交额。来源：7691615504809922291。 |
| **情绪风向** | 资金最大聚集地；昨天最靓（流入最多）的板块=今天情绪风向。它一旦承压，会带动指数与全市场情绪。来源：7687561396830636250。 |
| **杀伤型兑现** | 主线兑现后指数下跌、情绪恐慌、资金选择观望，全市场跟着 A。 |
| **分流型兑现** | 主线兑现后资金不观望、直接搬家到新板块抱团，指数稳住、多点普涨，短线情绪继续火热。来源：7687965336377256923。 |
| **掐独食 vs 主线趋势** | 高位两种结构：掐独食=单一批发商全程缩量无回调（天量见天价适用，一旦分歧断崖）；主线趋势=换手接力价升量增（缩量回调健康，放量震荡还有空间，放量滞涨=风险）。来源：7673058685740873074。 |
| **盘口 vs 明细** | 盘口=主动委托（挂在档口给你看，想挂就挂想撤就撤）；明细=主动成交（红=主动买、绿=主动卖、黑=中性撮合，3 秒合并会失真但宏观趋势不失真）。来源：7656819115626257318。 |
| **爆量（开盘爆量）** | 9:30 开盘瞬间分时量出现红绿柱子对撞巨量=新大商直接接走抛压的换手信号；断反上是大商要做事，平时是踩点。来源：7675735733755339430。 |
| **踩点 vs 试错** | 踩点=提前埋伏好看但短期没起来的票；试错=题材苗头出来后多上点菜试热度是否传导到自己票。来源：7679425145450521522。 |
| **求证阶段** | 凭盘感判断行情阶段后，先用小仓位求证，走出来印证了再集中精力做；这一步控制 80% 回撤。来源：7688677254108980571。 |
| **支撑/压力** | 前期筹码大量集中成交的位置；带长上影的高点压力>普通阳线；放量冲过去压力变支撑。来源：7680906083942021322。 |

## 一、选股（审美与筛选）

### 1.1 硬过滤条件（同花顺动态分组）
来源：《一年十倍平时是怎么筛选股票的》(7591063968602395507)、《七倍战法·断板反包》(7589981942104329499)

- ✅ 4 个交易日内出现过涨停（首板异动候选）
- ✅ 主板，**剔除 ST、剔除 301/创业板**（20cm 量价逻辑完全不同）
- ✅ 流通市值 **30–50 亿最佳**；<150 亿公式可用；**>100 亿不做**（量算不准、吃大盘情绪）
- ❌ 2–3 元低价股不做（量化老庄上下震荡玩死人）
- ❌ 有利空消息、业绩雷、监管处罚的不做
- ❌ 历史涨停稀少、一年出不了两次板、像心电图的死股不做

### 1.2 形态与位置
来源：《新手必看·高胜率低风险战法之断板反包》(7589215350781707506)、《断板反包通天代》(7595170642812932787)

- **位置**：底部长期横盘后、或上升趋势回调到一半位置横盘后出现首板；**不能是已经涨了一大波之后的高位板**。
- **首板**：最好是**缩量跳空板**（卖方惜售、买方抢筹=主力高度控盘）。
- **洗盘**：次日必须接一根**放量大阴线**，砸得越深越好，本质是一次洗到位。
- **护盘**：洗盘后小阴小阳缩量，**不破首板开盘价/跳空缺口/5–10–20 日线**；可出长下影收回。
- **反包**：最后一根放量大阳吞掉洗盘大阴。

### 1.2.1 断反模式当下阶段性变化与新分支（增量新增）
来源：《老粉向：断反模式当下阶段性的变化》（2026-10-10，https://www.douyin.com/video/7695031901371664585）

- **模式周期论**：市场风格在变，模式本身也有周期。去年下半年是短线行情，靠异动断板之后开启二波；今年年初切换为科技大趋势行情；有涨就有跌，科技周期结束后大部分开始回落，回到无人问津阶段——此时低位围绕 250 日线爆量的图形开始冒头。图形千差万别，但底层逻辑不变（涨停洗盘反包/断板反包），只不过不能再按以前的知识去硬套。
- **异动开端变化**：原断反逻辑是"横盘吸筹→缩量板异动→放量大阴洗→护→反包"；当下更看重"爆量加异动"——**不再以缩量板为开端**，而是在这之前要有任何一个爆量、或任何一个板，都可称之为异动的开端。
- **围绕 250 日线的三种形态**（当下个人研究较多的异动）：①一字跳空 250 日线；②爆量突破 250 日线；③250 日线附近爆量。虽然图形千差万别，但底层逻辑差不多，底下的成交量也都是在 250 日线这一块开始爆量。
- **相对低位[存疑]**：博主个人模式偏向低位的后排反包，前提是低位。但高位低位是一个**相对低位[存疑]**——票本身位置虽在上面，但若之前有一段很长时间的沉寂期，沉寂期拉得越长，在语言上面它也能算一个相对的低位[存疑]。
- **低位第一个异动多为试探**：在当前相对低位周期里，之前大部分都是从上面下来的，这种往往抛压很重，所以一般第一个异动都是一个试探，会大大降低往后的容错率；因此要在之前外加一个爆量的异动来充当这个试探（爆量异动打底）。

### 1.3 题材与板块地位
来源：《主线板块里的五种角色》(7626652017447979850)、《资金进出的真相》(7624487916433322226)、《题材情绪战法都要服务于你的交易模式》(7679425145450521522)

- 方向第一：选**当下最热主线**里的票，"大哥老了依然是大哥"。
- 先分清自己候选票在板块里是**大哥/老二/小兵/预备役/篡位者**。
- 只做**大哥或大哥的核心跟随**；后排跟风在板块分歧时最容易先 A。
- 大盘全线普涨时真假混在一起最难选；板块强弱一眼可分时反而好选。
- **板块情绪观察标的**（仅观察风向、不直接操作）：煤炭看云煤、旅游看桂林、消费看国芳、有色小金属看金钼、MLCC 看双星、电力看闽东、网安看中心等（来源：7685734523330447434，按行情切换动态更新）。
- **模式 > 题材 > 选股**：先有执行力/纪律/自己的店（模式），再用题材情绪去服务它；别上来就学图形摆盘，不知道客人流行吃什么。

### 1.3.1 踩点与试错
来源：《题材情绪战法都要服务于你的交易模式》(7679425145450521522)

- **踩点**：遇到"好看但短期没起来"的票，先小仓位埋伏，别等它流行起来才发现手里没货。
- **试错**：题材苗头出来但还没轮到自己票，多上点菜试热度是否传导；错了老实认错，复盘时去找题材的原因（是不是辨识度不够、是不是跟风后排），别去找图形的原因。

### 1.4 审美（一票否决）
来源：《交易里很抽象但是能避开很多坑的思路》(7623751776093142706)、《如果是你会怎么办·断20》(7636766551081818522)

- 在脑子里把未来走势画出来，看是否合理、均线是否跟得上、结构是否干净。
- "气质不对、气场很乱、走得墨迹拖泥带水、上下无章、看不到逻辑"→ 直接 pass，不研究。
- 不是它一定不行，而是它不在你"舒服、清晰、可控"的区间里。

## 二、看盘流程

### 2.1 盘前（前一晚 + 早上 8:30）
来源：《小白不知道怎么复盘》(7619318579067199398)、《单一指标从来不是判断唯一标准》(7628199212378926746)

1. 记录隔夜外围（美股、A50、消息面、政策）。
2. 对持仓/自选做**三个假设**（高开/平开/低开）和**三个计划**（对应每种开盘怎么做）。
3. 早上 8:30 起床洗脸跑两圈，把笔记过一遍，**开盘前先把自己的主见端出来**——不能开盘后脑子空空。
4. 对候选票提前定好：明天怎么开才算符合预期（跳空高开/平台上行/回踩5日再上/逼开不上），哪种开法是健康的。

### 2.2 集合竞价（9:15–9:25）
来源：《想看懂集合竞价？先看懂自己是哪类人》(7631550440564463497)、《别再盯着集合竞价了》(7593714186867327642)

- **9:15–9:20**：可随意挂撤单，主力常用 A 账号挂涨停单造假象，**参考价值极低**。
- **9:20–9:25**：可申报不可撤单，这 5 分钟才是真实博弈，**只看这一段**。
- 主力套路：A 账号 9:20 挂高拉竞价，B 账号低位埋伏，9:30 高开诱多后 B 账号高位出货。
- 对普通人参考意义极低——散户看不到真实挂单结构。仅连板选手/隔夜消息党/反包做 T 党可参考，其他人别迷信。

### 2.3 盘中（重点 9:30–10:00 黄金半小时）
来源：《放量缩量不会看？》(7615595990695702182)、《一年十倍平时怎么看盘》(7600758155731830706)

**小本本记录法**（提前 2–3 天对自选票建立基线）：
- 昨天全天总量、早盘 10 分钟量、最高/最低对应量。
- 今天同期对照：
  - 跌得比昨天多 + 量比昨天大 → **放量下杀**（警惕出货）
  - 跌得比昨天多 + 量比昨天小/持平 → **缩量下跌**（洗恐慌盘）
  - 总量比前一天多一半以上 → 放量；反之缩量回踩。
- 冲高回落先找压力位：前高、头顶均线；突破压力需要流通市值约 1% 的量，量不够一碰就下来。

**盘口盯盘要点**（来源：《资金进出的真相》7624487916433322226、《我平时看盘的状态》7649348350873580142）：
- 档口大压单消失：看明细是**被主动吃掉**还是**偷偷撤掉**——前者是承接，后者是诱多。
- 大托单消失同理。
- 明细里识别：量化整齐挂单（556/60/70/80，每 1–2 档一单）、对倒单、主动性中大单。
- **加权平均线**：价格在均线上方放量打架=高级别玩家入场；在下方缩量震荡=没人管。

**量化识别**（来源：《怎么区分量化与机构》7621138352410207218、7620384989661874291）：
- 9:30 九十度角直线拉、毛刺状分时、小梯子形态、量能逐波递减、2:50 突然直线、板上反复分单不坚决。
- 量化主导的票别跟它做 T，它到位置就走。

**盘口 vs 明细（增量新增）**（来源：7656819115626257318、7661204021366509490、7668790927716119882）：
- **盘口**=主动委托，挂在档口给你看，想挂就挂想撤就撤，参考意义弱。
- **明细**=主动成交：红柱=主动买（吃卖单）、绿柱=主动卖（砸买单）、黑=中性撮合；3 秒合并会让单笔颜色失真，但**3 秒内总金额汇总不会变、大趋势不会被掩盖**。
- **承接识别**：下跌时大卖单（1000 万+）砸下来，看是否有同量级大买单顶上（如 -5% 位置连续两笔 1000 万接=承接重）；如果卖单比买单多但股价已经在 -5% 且资金基本持平=承接还在。
- **早盘吓你识别**：9:30–9:40 密密麻麻小绿柱、没有 300/500 万以上大绿单=主力在吓你，不用慌。
- **跳档扫单**：一笔大红柱从 3.00 直接扫到 3.03，说明要干什么，看跳档后的大单方向即可，中间细节不重要。

**分时成交额分段拆解看资金强度（增量新增）**（来源：《分时成交额，快速看懂资金强度》，2026-10-02，https://www.douyin.com/video/7691970101378137690）：
- **分段拆解**：把全天分时成交额按拉升段/回落段拆开看资金强度。案例：全天总成交额 1.8 亿，早上第一波拉上来 3000 万，随后回落砸下来 8000 万（也就是说中间这一段是 5000 万），再拉上来 1.48 亿（这一段将近 7000 万），最后收个小十字星。
- **增量判断**：比较拉升段与回落段的成交额——拉升阶段比回落阶段只多了那么一点点，说明增量资金入场不明显、强度还差一点；若后面拉升阶段能给到 1~1.5 亿左右，才会更重视。核心是用来判断**有没有增量资金入场、值不值得去关注**。
- **用途定位**：这是对**隔日预期**的参考（当天要么是一个脉冲，要么是一个深 V[存疑]），**并不是买卖依据**。
- **复盘训练**：短线哪怕是老手，拼的都是瞬间的判断，不会坐下来慢慢拆解；要么有天赋，要么靠大量的复盘训练，天生反应慢的不要去硬做。

**开盘爆量信号**（来源：7675735733755339430）：
- 9:30 开盘瞬间分时量出现红绿对撞巨量=新大商直接接走瞬间抛压，不是慢慢承接。
- 在断反护盘日出现=新大商进场成本明牌，增加反包概率；在平时出现=大商踩点，值得观察。

**异动与爆量的本质：批发商进场标记（增量新增）**（来源：《资金到底来了没？异动爆量到底是啥？》，2026-10-05，https://www.douyin.com/video/7693152471052571034）：
- **批发商进场两种方式**：①如果大家都看好、有人卖了他才能买→**阶梯式逐步放量**，一点一点买上去；②如果只有他一个人看好→**瞬间吃掉所有挂单，价格一根直线拉上来，瞬间一根巨量柱**（同样也可能被另一个同等体量想兑现的人集中砸盘，瞬间又给他砸下来）。
- **异动=有资金进场交手的标记**：不管最后拉升成功还是被砸下来，有一件事是可以确定的——**有批发商进场交手了**，这个就是异动；它的价值在于这里不再是一潭死水了。
- **标记加验证**：异动之后是"标记加验证"——后续若走出预期内的图形，说明这个活跃的批发商还留在里面，这是自信、也是博弈的理由。人性偏爱规矩和平淡、下意识回避剧烈波动，但恰恰活跃的多空厮杀波动才能说明有资金在里面博弈；如果真的是一潭死水、连个异动都没有、无人参与，那自然也就没有行情。
- **低位发动行情前要有异动打底**：如果在低位想要发动行情，那么在之前要有一个资金博弈的异动打底；没有这个，很突兀地突然来一个缩量的上涨，那很容易是虚的，可能隔天连溢价都没有（**缩量拉升易虚**）。
- **爆量越大越在乎**：爆量也就是这一瞬间的拉升，它的成交越大，说明进来的越多、人家越在乎；如果是缩量的拉升，那就有点本末倒置了。
- **批发商有耐心，要等验证**：批发商体量越大越不缺时间，10 天半个月甚至一个月没动静都有可能；但体量越大同时也越不会那么轻易认亏离场——只要我比他有耐心。可以观察、可以验证，但是不要着急。

**顶底背离实战辨析：结构背离 vs 情绪背离（增量新增）**（来源：《顶底背离实战：为啥一看就懂，一用就失效？》，2026-10-11，https://www.douyin.com/video/7695340845284722906）：
- **底背离定义**：价格持续新低，但是 MACD 不破新低（价格在持续走低、抛压在缩量）=底背离，就这么简单。指标也会被位置和环境所影响，情绪很差、4000 多家下跌的时候它也是会失效的。
- **情绪背离（比较好分辨）**：本身图形、位置、支撑都是合格的，是被大盘情绪被动带崩的**假跌破**——价格被情绪破了支撑出现了新低，但是 MACD 没有跟随新低；里面的人不想出、外面的人因为环境不好也不想进，没有真实的恐慌盘。只要情绪稍微有所好转、或者批发商稍微承接一下，会很轻松地拉回 V 形。
- **结构背离（比较坑）**：破了支撑之后，MACD 也跟随着价格在持续的新低，**一边抛一边接**；它一旦接不住，后面可能就还有新低——**这个就不算是有效的底背离**，新手对它不是那么好拿捏。
- **结构阴跌（更坑）**：没有护盘、没有承接、没有资金助力；**缩量不是空头的衰竭，而是单纯的根本就没有人玩**——这种你给它 10 次底背离，它后面还会出现 10 次阴跌。
- **流动性枯竭行情中一切指标失效**：在非常极端的情绪环境里，任何指标都是会失效的。**流动性枯竭行情**=市场的集体恐慌、系统性的抛压，它不是个股的博弈，所以在这里任何背离、量价形态都是没有参考价值的。
- **使用顺序**：**先看位置，再看承接、资金助力、情绪环境，最后才是参考形态指标**。盘中的分寸、强弱、真假背离，都是靠大量的实战堆积出来的，没有捷径、也没有秘籍。

**尾盘偷袭识别**（来源：7689747115191633114）：
- 全天水下震荡，下午/尾盘一根直线拉到 6–8 个点，收长上影（收盘只涨 1–2 个点）。
- 底层：游资/量化/大商博隔夜溢价，或大商动用小部分资金拉抬吸引跟风、次日分批出货。
- **超短遇到这种，隔天直接兑现离场**，不幻想它是震仓抢筹。

**早盘找情绪风向**（来源：7687209172232780891）：
- 9:30 第一时间先看**当天板块异动**，找前排情绪龙（第一时间异动并能带动板块的首板）。
- 独立消息、冷门板块、带不动板块的首板**不算**情绪风向。
- 看到板块异动后，第一时间在脑子里筛：谁是前排？谁是后排？谁是有辨识度的老朋友？优先做**有过爆量迹象+回踩支撑**的后排，而非一根直线拉起来的。

**口诀**：**高开看兑现，低开看承接，放量看情绪风向**（7686856168170680713）。

## 三、进场（买点）

### 3.1 断板反包标准买点
来源：《一个视频让你看懂十倍图形断板反包》(7590348715626820466)、《12号断板反包复盘》(7617086997110875762)

- **买点 A（护盘低吸）**：洗盘大阴之后，股价砸到首板开盘价/缺口/20 日线附近，**长下影收回、缩量小阴小阳守住支撑**时介入。博主原话："我比较喜欢在他护盘的当天，砸穿这个支撑的时候去找他，90% 的逻辑 + 10% 的运气。"
- **买点 B（反包确认）**：第二天**跳空高开或平开后放量上攻**，第一波拉升成交额达到流通市值 0.5%（有效放量），且冲破前一日压力位时跟入。
- 反包板所需量：流通市值 **1.5%–2%**（比首板 1% 要大，因为上方有洗盘套牢盘）。

### 3.2 分层阶梯低吸
来源：《阶梯式分层低吸》(7645450837200588233)

- **第一档、第二档**：小仓位试错（1/4、1/4），测试下方承接。
- **破位风险隔离**：若跌破关键位（如 5 日/10 日/20 日线），**不见兔子不撒鹰**，停下来观察。
- **第三档**：确认形状符合逻辑、价格回到均线支撑（5/10/20 日），把剩余仓位**集中打在这一档**，摊低成本。
- 前提：标的自身逻辑没坏；如果一边倒破位坏掉，就停手不补。
- 优点：错了前面两档小亏，对了三档集中吃到主升，成本天然偏下。

### 3.3 日内做 T 买点
来源：《做T必看·顶底背离BS点》(7586990148782050587)、《如何用量价顶底背离日内精准做T》(7605942257728075118)

- **B 点（日内低吸）**：股价创新低、MACD 不创新低（底背离），且成交量萎缩到前期一半以下甚至地量 → 接回。
- 配合支撑位：5 日/10 日均线、前低。
- 大环境单边一致向上时，背离会失效（被被动推上去），别硬做。

### 3.4 爆量信号买点（增量新增）
来源：《加更一条干货，看懂开盘爆量信号，防止卖飞》(7675735733755339430)

- **触发**：断反护盘日（或平时观察票）9:30 开盘瞬间出现分时量红绿对撞巨量。
- **含义**：新大商直接接走瞬间抛压，不是慢慢承接——这是新资金明牌进场成本。
- **动作**：不要因为"硬躺了几天身心摧残"就一有信号立刻卖飞；爆量对撞是换手信号，观察后续承接，反包概率提升。

### 3.5 高难度打野（谨慎，增量新增）
来源：《两种高难度打野》(7684985982593299442)

- **模板被摁**：大商自救——逻辑还在、情绪还在、题材没问题，大商就会自救。
- **形态偏好**：**-8%、-9% 不跌停**的强势反弹；短期跌幅大、风险充分释放后反弹爆发力才强；今天跌一点明天跌一点的"阴跌"反而不做（不够彻底）。
- **龙虎榜识别**：榜上三类人——大公司（批发商）、大商贩（知名游资）、拉萨（小商贩）。**5 个席位里 4 个在进，但核心批发商/大商贩在出=差榜**，别上。
- **失败教训**：位置高+人气高是双刃剑——小商贩太多，没有大商贩愿意来抬轿（吃不下），就没有承接。
- 难度极高，情绪/题材/逻辑/技术缺一不可，**不要照葫芦画瓢**。

### 3.6 求证阶段（增量新增）
来源：《控制80%回撤的底层：交易里的求证意识》(7688677254108980571)

- 凭盘感判断当前行情阶段（妖股反抽/主线梯队/高切低/老龙反弹/轮动抱团）后，**不要孤注一掷**。
- **动作**：拿小仓位求证判断对不对；走出来印证了，再集中精力做这个方向。
- 缺少这一步=行情一换就凭感觉出手，回撤会很大；这一步**控制 80% 以上回撤**。

### 3.7 进场前置 checklist
- [ ] 它在主线题材里吗？是大哥还是小兵？
- [ ] 流通市值在 150 亿以下、不是 ST、不是创业板、不是 2–3 元死股？
- [ ] 位置是底部/中继横盘后，不是高位？
- [ ] 首板缩量跳空？洗盘大阴放量大？护盘缩量守住支撑？
- [ ] 今天大盘情绪配合吗？是退潮期还是上升期？
- [ ] 第一波拉升成交额达到流通市值 0.5% 了吗？
- [ ] 盘口大压单是被吃还是被撤？

## 四、出场与风控

### 4.1 止损（硬规则）
来源：《涨停第二天咋处理》(7625962181692490738)、《新手必看·断板反包》(7589215350781707506)

- **破位止损**：护盘阶段跌破首板开盘价/跳空缺口，**次日不能收回** → 洗盘变砸盘，止损走人。
- **鳄鱼原则**："当鳄鱼咬住你的脚，你一定要在它咬住你整条腿之前果断挣脱。"没有固定离场位，只有必须守住的底线。
- **放量破位**：洗盘后若放量跌破支撑，不抱幻想，直接走。
- **高开一根直线下杀**：9:30 后 3 分钟内无承接 → 放弃，不抄底（三种情况：情绪一日游杀、拉高出货、真利空）。

### 4.2 止盈与格局
来源：《涨停第二天咋处理》(7625962181692490738)、《1号断板反包试验品成功》(7592104136608037322)、《7号作品复盘》(7603359427438598473)

- **涨停不是终点，是保护节点**：涨停后第二天先搬一半出来建立安全垫，剩下的在无风险区间奔跑。
- **反包成功后不格局**：博主原话"6 个点够了，不跟他谈恋爱，外面五千多个票等我选"。
- **反包上不了板**：当天反包但封不住板，冲高就 S 一点；反包强度决定后续空间。
- **远离 5 日线 + 高开**：短期获利盘抛压大，通常要回踩 5 日线；此时高开=卖点。
- **日内顶背离 S**：价格新高、MACD 不新高、成交额缩到前一波一半/1/3 → S 点。
- **高位价平量增**：远离 5 日线后突然放大量但价格不涨（多空分歧加大）→ 警惕，准备走。
- **连续长上影 + 爆量**：高位"闭了一针"，出货信号。

**高位放量的两种结构（增量新增）**（来源：7673058685740873074）：
- **掐独食（情绪炒作，单一批发商全程缩量无回调）**：一旦批发商不计成本大批量往外丢，瞬间接不住，断崖下跌——**天量见天价**仅适用于这种结构。
- **主线趋势（换手接力，价升量增）**：
  - **放量震荡**：老批发商大批丢、新观望者大批接，势均力敌、上不去下不来 → 还有想象空间。
  - **放量滞涨**：大批量往外丢但价格始终上不去、天天冲高回落、观望者热情衰退 → **风险快速放大**，准备走。

**尾盘脉冲兑现（增量新增）**（来源：7689747115191633114）：
- 全天水下、尾盘一根直线拉到 6–8 个点收长上影 → 隔天大概率低开无溢价，**超短隔天直接兑现**。
- 只有在"板块情绪共振+同板块多只走强+拉升后不大幅回落"时才是例外，不要幻想小概率。

### 4.3 做 T 高抛
来源：《一个视频告诉你如何精准判断日内最高点》(7584774807298166042)、《纯干货·成交量公式案例》(7594400248794985190)

- 第一波拉升放量（如 4000 万），第二波价格新高但量缩到 3000 万 → 顶背离，S 一半。
- 第三波再拉到接近涨停但量只有 3200 万、不够上板所需流通市值 1% → 全 S。
- **量是热闹、额才是真金白银**：价格新高但成交额不创新高 = 没有高级别玩家接盘。

### 4.4 风险控制总纲
来源：《涨停第二天咋处理》(7625962181692490738)

> "以保护收益为核心，跟随市场情绪，通过建立安全底线，实现风险与收益的不对称优势。" —— 引利弗莫尔"截断亏损让利润奔跑"+索罗斯"重要的不是对错，是对的时候赚多少、错的时候亏多少"。

## 五、情绪周期与大盘环境

### 5.1 情绪周期阶段
来源：《当下断反务必注重范围提高审美》(7633397640059254427)、《集体异动情绪退潮》(7594458113005323442)

- **情绪宣泄**：一轮集中宣泄通常 3–5 天完成释放。
- **混沌窗口**：宣泄后不会立刻反转，进入无明确龙头、高低快速切换、容错率压缩阶段。此时**只做少数核心抱团**，非主流边缘票往后放。
- **集体加速日**：所有热点一起高潮、后排跟风烂板/炸板 → 第二天分歧概率大，不追高。
- **退潮期**：热点板块龙头加速后烂板回落 = 板块分歧开始，后排回调概率大；可从中**弱留强**找反包方向。

### 5.1.1 完整一轮情绪周期三段式（增量新增）
来源：《3天视频带你看懂完整一轮市场情绪周期》(7688262292614664434)、《情绪风向/高开回落/存量博弈一次讲透》(7687561396830636250)、《兑现了为啥没崩？杀伤型/分流型兑现》(7687965336377256923)

以"昨天最靓板块=今天情绪风向"为主线：

1. **Day 1 情绪火热**：大盘放量上涨，3 号板块流入最多=最靓的仔。
2. **Day 2 早上高开猛冲**：
   - 若 3 号高举高打、量能跟上、带动指数+细分板块=变成主线；
   - 若 3 号高开放量但里面一半往上一半往下（对倒换手），午后量跟不上→**高开回落尾盘跳水**（祖训），因为存量市场进去的人比不上出来的人。
3. **Day 2–3 兑现方式分两种**：
   - **杀伤型兑现**：3 号兑现没人接、指数跌、情绪恐慌、资金观望 → 全市场 A。
   - **分流型兑现**：3 号兑现但资金搬家到新板块（多点抱团、全面普涨）、指数稳住 → 3 号不再是风向，新板块接棒；短线情绪继续火热。
4. **Day 3 分歧加重**：一部分搬家一部分观望、高标掉队、新承接板块没持续放量 → 轮动加快、所有热点变一日游脉冲 → **不适合激进进攻**。

**存量市场两信号**（7667881594728227209）：①量能能否跟上；②热点题材能否延续。两者缺一=电风扇、脉冲就熄火。

### 5.1.2 冰点与拐点（增量新增）
来源：《7月16日透出微弱转机》(7662978718718200486)、《如果连我都感到心累了》(7663445177231369802)、《熬过一轮调整，拐点在哪里》(7663079676868929737)

- **冰点特征**：大基数都遭不住、博主视频流量差、无人问津、死扛的都走了、接近地量。
- **拐点信号**：加速下跌后**接下来几天不创新低 + 量能补上来**=阶段恐慌尾声；反之继续。
- **头天之后**：稳住头天会筑底震荡，不要太亢奋；先手博弈=以最小风险搏稳住头天。
- **缩量调整良性判断**：4 连阳后缩量一天调整、全场只有 2 家跌停、成交额少 2000 亿=共识还在，把短线获利换出去而已，不是变盘（7672748806642906738）。
- **4000 点/250 日线压力位**：接近时缩量回调=大家还有一鼓作气想法；**冲到 4000 点放量但没冲上去=分歧出现**，才要警惕。
- **关键压力位压制题材情绪**：指数上方同时挂着 4000 点与 250 日线时，**利好驱动型题材会迎来情绪降温**，追利好驱动需谨慎（来源：7680507344783305702）。

### 5.1.3 成交量底层逻辑（增量新增）
来源：《成交量的底层逻辑：缩量共识，放量分歧》(7670123187519574643)、《放量突破真的正确吗》(7671318993172484937)、《分清有量没额的本质》(7691615504809922291)

三句话核心：
1. **没有对手盘就没有成交量**；缩量=大家观点暂时统一（共识）。
2. **放量=分歧变大**：一拨人想落袋、一拨人想进场，货物大规模换手。
3. **放量 ≠ 有人进场**：只是大规模交换货物，关键看谁在主动拿货、谁在甩货。

- **成交量 vs 成交额**：成交量=人气/活跃度/趋势信号（放量突破、缩量变盘）；成交额=玩家级别/行情级别（真金白银）。小草原启动只有量没有额=小散游资凑热闹，持续性差。
- **假突破**：突破压力但成交额增幅不大=低位区间打架，高位没人接。
- **有量没额（虚承接）**：价格大跌量放大但额没变=场内存量低位互道，长下影看着像承接其实是虚的；真反转要增量资金同步放大额。
- **横盘虚量**：量化高频+场内存量来回刷手数，隔天无溢价。

### 5.2 大盘环境对应动作
来源：《行情好时看技术，行情坏时看操作》(7647884785952380361)、《环境不好的时候别总找自己问题》(7618935949938038427)

- 环境正常：技术、指标、眼光都正常发挥。
- 环境差：**操作 > 技术**，比的是盘感、心态、执行力。
- 环境极差（满屏绿、不到 500 家红）：**不要找自己的问题**，先出来，但持续跟踪自选。
- 大情绪差时资金会**抱团避险**到人气核心，此时人气+方向+抱团=逆势走强逻辑（但不确定性高，只在情绪特别差时娱乐仓参与）。
- 交割日（每月第三周周五股指、第四周三 IF、倒数第 2 工作日 A50）：机构平仓会放大波动，不是决定方向但会放大涨跌，提前减仓看戏。

**支撑与压力（增量新增）**（来源：7680906083942021322）：
- 压力=前期筹码大量集中成交位置；带长上影的高点压力 > 普通阳线（冲高回落留的位置抛压更重）。
- 均线（60 日、250 日）、前期平台高点都是压力。
- **放量冲过去并站稳 → 原压力变支撑**，回踩这里是买点。
- 不要把支撑压力当绝对规律，它只是辅助交易计划。

**节前效应（增量新增）**（来源：7690136658025157862、7690891052618524070）：
- 节前资金不想大举进攻，要么全面普涨要么巨大分化。
- **周二是节前分歧最大的一天**（想取钱过节的兑现+想博弈节后的承接对倒）。
- 周三最后一天基本缩量小阳/小阴，下午少量资金埋伏博弈节后；这种小阳线没溢价。
- 操作：周一有兑现情绪先离场，周二盯分歧做决定，最后一天不下重手；**老规矩清仓/轻仓过节**，除非极端情况留底仓博弈。

**外围与数据（增量新增）**（来源：7682002719648858570、7686222548111055974、7679772490851583643）：
- 非农/CPI/美联储议息：教科书式传导链（就业强→不降息→利空科技贵金属）只能作为情绪开头，**不改变 A 股自身节奏**；高开低走是常态。
- 月线 MACD 死叉≠马上大跌，是以月为单位的震荡周期，别听风就是雨。
- **ETF 份额净流出 + 价格在涨**=人在撤退，反弹持续性存疑（7673451652430634138）。
- 临近业绩披露期：没有基本面、纯情绪题材要减仓，"故事阶段结束、开始交成绩单"，一纸财报改写形态。

### 5.3 主线板块角色与所处阶段
来源：《主线板块里的五种角色》(7626652017447979850)

完整链条：大哥带头冲 → 老二稳信心 → 小兵气氛组捧场 → 龙头累了预备役顶席 2–3 天 → 龙头老了篡位者取而代之。
- 识别板块走到哪一阶段，就知道今天该看谁、该躲谁。
- 小兵（跟风）在大哥撤之前必须先跑，它比大哥跑得还快。

## 六、资金管理与纪律

来源：《周末走心闲聊：自制力、仓位、资金体量》(7640833697294783398)、《仓位管理实践案例》(7603740663402363314)

### 6.1 仓位规则
- **同时持仓最多 2 只**，一半一半。
- **高位票用 4 成拆火**（应对继续洗盘/破位做 T）；**低位票用 6 成拆火**。
- 远离 5 日线时先 3 成踩点，第二天回踩 5 日线再补 3 成做 T。
- 体量 200–300 万以上不要一次性全进（会被看到、被针对），拆开一点点进。
- 正面/反面仓位要平衡，不正面小反面大，只要最终正面期望 > 反面即可。

### 6.2 纪律
- **交易你的计划，计划你的交易**（达利欧）。只在能力圈内做事，认知外的波动不纠结。
- **以数练身，以道控局，道术合一**。脱离环境硬套形态风险极高。
- **不跟风、不忙从不追涨、不杀跌**，守住自己节奏。
- 空仓也是操作；看不懂就空仓等待，机会永远留给有准备的人。
- 决定做一件事后不听任何人意见，错了认，对了继续下一个，只看总账。
- **顺风易膨胀，膨胀破纪律**：连续盈利后最容易"没有严格执行自己的交易纪律"——下手重、保留侥幸心理、持仓被动；越是太顺越要回到计划，人都会有不执行的时候，错了就认，别把顺风当能力（来源：7680507344783305702）。

### 6.3 控制回撤（增量新增）
来源：《狼哥陪你们一起复习，控制回撤，复习交割》(7680150560163841446)、《一名合格的猎人，要学会保住枪里的子弹》(7677916546585624522)、《9月12号周末总结》(7684619463241498094)

- **大回撤绝大多数来自做了不属于自己模式的交易**——模式内该做做，模式外坚决不做、不看。
- **止损不是认输**：到了止损点逻辑没坏，可以做 T/滚动降成本锁死在可承受范围；要么一开始果断离场，要么坚持下去别摇摆（摇摆=精神三重折磨，倒在半路）。
- **正常回撤 vs 失控回撤**：
  - 正常：市场震荡周期+模式连续失败周期，曲线小幅波动，不用否定模式。
  - 失控：连续多笔亏损+曲线持续下滑 → **停下来复盘，别硬扛着想一把做回来**。
- **防守 ≠ 空仓**：感觉不好但不确定时=防守（减仓/收缩）；100% 确定风险时才=空仓。行情不好但你的曲线不动=防守的价值。
- **拥挤度**：短期堆积大量获利+成交额没持续放大→资金难持续集中抱团，主动收缩仓位看风格切换（7651966858791690826）。
- **猎人子弹论**：市场从来不缺机会，"猎人没了子弹才是什么都没了"；存量缩量+电风扇+财报期，别逼自己天天交易，要克制。
- **求证阶段**：见 3.6，小仓位求证行情阶段，对了再加——这一步控制 80% 回撤。

## 七、复盘方法

来源：《小白不知道怎么复盘》(7619318579067199398)、《一年十倍平时怎么看盘》(7600758155731830706)

### 7.1 每日复盘流程
1. 记录今天哪块最强、哪块最弱、为什么。
2. 把当天影响盘面的消息一条条对号入座。
3. 看隔夜外围（凌晨 4 点美股收盘）作为情绪参考。
4. **对明天做 3 个假设**（涨/平/跌概率）+ **3 个计划**（每种情况怎么办）+ 明天优先关注哪里、哪里不碰。
5. 盘后对照：实际走了哪种？自己判断对了还是错了？为什么？
6. 记录每笔交易：**进的理由、出的理由、对错、是否符合计划**。

### 7.2 持续跟踪
- 认可的标的**不删自选**，持续观察；哪怕这次走坏了，它后面只要"来了"就一定会动。
- 复历史案例：断板反包一号到十号每个案例都拆，量、均线、背离、板块地位全部串起来看。
- 每天盯盘 1 分钟 1 分钟的信号，看多了形成盘感——"老电工摸一下就知道有没有电"。

### 7.3 每月交割单复习（增量新增）
来源：《狼哥陪你们一起复习，控制回撤，复习交割》(7680150560163841446)、《牢骚太盛防肠断》(7689038445982016494)

- 每月末把当月交割单拿出来**一笔一笔复盘**，不要只盯胜率。
- 找自己**做起来最舒服、最契合性格**的模式：对的怎么做更好？错的怎么避免？下月就钻这个。
- 胜率 50% 已经很不错；曲线不上不下时，重点复盘**控制回撤**而非提高胜率。
- 月末总结四件事：仓位管理、节奏把控、心态不急不躁、进攻与防守时机。
- 复盘时区分：模式内亏损=正常波动；模式外亏损=失控，下月坚决不做。

## 八、CheckList 汇总（触发条件 → 动作）

### 8.1 盘前
| 触发 | 动作 |
|---|---|
| 昨晚美股大跌 / 重大利空 | 降低预期，候选池砍半，仓位减半 |
| 自选票出现新涨停/大阳 | 加入观察，启动断反四步追踪 |
| 交割日/周五/节前 | 保守，不新开仓，看戏 |

### 8.2 选股
| 触发 | 动作 |
|---|---|
| 4 天内有涨停 + 主板 + 流通 30–50 亿 + 主线热门 | 加入自选观察 |
| ST / 创业板 / 2-3 元 / 流通 >150 亿 / 有利空 | 直接剔除 |
| 高位放量板后再板 | 不做（成功概率小、空间小） |
| 形态"气质不对"、墨迹、无逻辑 | 一票否决 |

### 8.3 进场
| 触发条件 | 动作 |
|---|---|
| 洗盘大阴后缩量小阴小阳守住首板开盘价/缺口/20日线 + 长下影 | 低吸买点 A，1/4 仓试 |
| 次日跳空/平开后放量上攻，首波成交额 ≥ 流通 0.5%，冲破压力 | 加仓到 1/2–2/3 |
| 价格创新低 + MACD 不创新低 + 地量 + 到均线支撑 | 做 T 接回 / 分层低吸第三档 |
| 第一档二档试错后破位 | 停止补仓，等回到均线支撑再考虑 |
| 大盘情绪混沌、无主线 | 空仓或只做抱团核心 |
| 断反护盘日 9:30 开盘爆量对撞 | 新大商明牌进场，别卖飞，观察承接 |
| 凭盘感判断行情阶段后 | 先小仓位求证，对了再加（控制 80% 回撤） |
| 板块异动第一时间 | 找前排情绪龙/有爆量迹象的老朋友后排，不追一根直线拉的 |

### 8.4 出场
| 触发条件 | 动作 |
|---|---|
| 跌破首板开盘价/缺口，次日不收回 | 全部止损（鳄鱼原则） |
| 涨停后次日 | 先出一半建安全垫，剩余跟随 |
| 反包成功涨到 6%–7% | 不板就走，不格局 |
| 价格新高 + MACD 不新高 + 量缩到前波一半/1/3 | 日内 S 点，做 T 高抛 |
| 远离 5 日线 + 高开 + 无承接 | S |
| 高位价平量增（远离 5 日线放巨量不涨） | 警惕，准备走 |
| 高位连续长上影 + 爆量 | 出货信号，S |
| 9:30 一根直线下杀 3 分钟无承接 | 不抄底，放弃 |
| 尾盘一根直线拉 6–8 个点收长上影 | 隔天直接兑现，不幻想震仓 |
| 高位放量滞涨（主线趋势中天天冲高回落、接不住） | 风险快速放大，走 |
| 放量震荡（势均力敌上不去下不来） | 还有空间，继续观察 |
| 缩量弱修复 + 沪深 6000–8000 亿无增量 | 躺平少动，少量打野 |

### 8.5 风控与纪律
| 触发条件 | 动作 |
|---|---|
| 同时持仓 ≥3 只 | 砍到 ≤2 只，一半一半 |
| 单笔试错仓位 >1/4 | 退回，分层低吸 |
| 环境极差（红盘 <500 家） | 出来观望，不找自己问题 |
| 计划外的追高冲动 | 停手，打开前晚笔记对照 |
| 连续盈利、操作太顺 | 警惕膨胀心态，严格执行既定纪律与仓位，不因顺风加重手（来源：7680507344783305702） |
| 一笔交易亏损触及安全底线 | 无条件执行止损，不幻想 |
| 连续多笔亏损 + 曲线持续下滑 | 失控回撤，停下来复盘别硬扛 |
| 感觉不好但不确定 | 防守（减仓），不是空仓；100% 确定风险才空仓 |
| 节前周二 | 分歧最大，周一先离场；周三最后一天不下重手；轻仓过节 |
| ETF 份额净流出 + 指数涨 | 人在撤退，反弹持续性存疑，收缩 |
| 临近业绩披露期 | 纯情绪题材减仓，别接财报雷 |
| 冲高回落 + 量能午后跟不上 | 祖训：高开猛冲=尾盘跳水，别追高 |

## 附：核心口诀（博主反复强调）

1. **形态为先，资金为王**——二者缺一不可。
2. **有预期，资金才有意义；资金配合预期才能兑现**。
3. **量大是热闹，额才是真金白银**；短线看成交额不看成交量。
4. **任何指标都不是 100%**；单一指标不能作为判断唯一标准。
5. **图形会变，内在逻辑不变**——别死记图形，要理解主力意图。
6. **以数练身，以道控局**——脱离环境硬套形态就是送钱。
7. **你不是跟票谈恋爱**——外面五千多只票等你选。
8. **环境不好时，不要找自己的问题**。
9. **截断亏损，让利润奔跑**；风险与收益不对称。
10. **耐心是最顶级的天赋**——时间会替你说话。
11. **缩量看共识，放量看分歧**（增量新增，7670123187519574643）。
12. **高开看兑现，低开看承接，放量看情绪风向**（增量新增，7686856168170680713）。
13. **价格是情绪，成交量是博弈，更是认知**；放量≠有人进场，关键看谁在拿货谁在甩货。
14. **这个市场看的不是谁厉害，是谁能活得更久**（增量新增，7688262292614664434）。
