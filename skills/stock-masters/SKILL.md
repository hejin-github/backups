## 执行流程（每次触发必走）

### Step 0：智能路由（优先触发最匹配体系）

用户问题里有关键词时，**不要9个体系全出**，先识别最匹配的体系做主体分析，其他体系只在有命中信号时补充。

| 用户问题关键词 | 优先触发体系 | 主体分析重点 |
|---|---|---|
| 断板反包 / 反包 / 洗盘大阴后拉回 | **陈学长** | 流通30-50亿？四步走完没？买点对不对？ |
| 打板 / 一进二 / 二进三 / 断板就卖 | **湖滨** | 是不是真龙？上车点对不对？ |
| 情绪周期 / 退潮 / 冰点 / 龙头 / 弱转强 | **野人** | 七阶段哪段？是龙头还是跟风？ |
| 高量柱 / 量比放大 / 2.7倍量 | **陈哥** | 高量实底实顶在哪？ |
| 回踩20日线 / 四层共振 / MACD | **后山人** | 四层共振走完没？换手5-15%？ |
| 5日线 / 三点买入 / 做T | **小郭** | 离5日线多远？乖离率？ |
| 主力 / 吸筹 / 出货 / 低位堆量 | **大A梦想家** | 当前在哪个阶段？ |
| 换手率 / 筹码峰 / 内外盘 / 分时 / 封单 | **馒头** | 换手率档位？筹码形态？分时类型？ |
| 仓位 / 盈亏比 / Kelly / 回撤 / 期望值 | **巅峰操盘** | 期望值正负？仓位该多少？ |
| N字 / 妖N / 板前动作 / 盘感 / 334分仓 / 速度理论 | **凯心** | N字走完没？板前动作有没？678位置到没？ |

**规则：**
- 用户问题命中某个体系关键词 → 该体系做主体分析（详细）
- 其他体系有明显命中信号 → 补充一行
- 其他体系没命中 → 不输出
- 用户说"九套都看看" / "全部分析" → 才全量输出

### Step 1：拉数据
用 `seed_finance_lookup` 查两组：
1. `"&lt;股票名&gt; &lt;代码&gt; 最新股价 日K 成交量 换手率 均线 近期涨停"`
2. `"&lt;股票名&gt; &lt;代码&gt; 流通市值 所属板块 最新消息"`

### Step 2：先对齐事实表
输出个股关键事实：
- 现价 / 今日涨幅 / 是否涨停 / 封板时间
- 近 10 个交易日的连板序列
- 近 20 日累计涨幅
- 流通市值
- 所属板块
- 关键量价特征

### Step 3：九体系逐项对照

- **adreamer**：当前在吸筹/洗盘/拉升/出货哪一段？有没有低位堆量？
- **houshanren**：四层共振走完没？换手是否在 5–15%？
- **hubin**：潜龙/真龙/跟风？一进二上车点还是高位加速？
- **xiaoguo**：现价离 5 日线多远？三点买入法到位没？
- **chenxuezhang**：主板非ST？流通30–50亿？走没走断板反包四步？
- **chenge**：近5日有没有高量柱（≥昨日2.7倍）？换手是否>15%警戒？
- **yeren**：情绪周期七阶段哪一段？龙头/跟风？高位放量出货？
- **peak**：按索普概率论评估——期望值正负？盈亏比多少？单笔仓位该多少？回撤风险？
- **manttou**：换手率档位？筹码峰形态？内外盘关系？分时是拉高洗盘还是拉高出货？封单成交率多少？

### Step 4：输出对比表

| 体系 | 核心信号判定 | 体系内位置 | 操作结论 |
|---|---|---|---|

操作结论三档：
- 🟢 进场 / 加仓信号
- 🟡 持有 / 逢高减仓 / 观望等回踩
- 🔴 离场 / 不追 / 坚决回避

### Step 5：综合结论表

| 你的状态 | 操作 |
|---|---|
| 空仓 / 想买 | ... |
| 已持有（成本低） | ... |
| 已持有（成本高/今日追入） | ... |

列出 2–4 条关键风险点。
