## 1. 方法论（心法 / 交易哲学）

### 1.1 核心原则：不猜顶底，只看确定性与风险性
- 买自己能看懂的，卖自己看不懂的。
- 只要有确定性，无论多高都去做；只要看不懂，无论多低都卖。
- 不预测、不抄底、不猜顶；只做右侧。

### 1.2 敢于空仓
- 行情不好、买点没出现时，主动空仓是权利不是错误。
- "害怕踏空是亏得还不够多"——不要怕错过，要怕做错。
- 空仓是调节心态最好的方式；心态乱了怎么操作都是错。
- 只在确定性最强的位置出手，不提前打光子弹。

### 1.3 交易的本质是心性，不是技术
- 技术短时间谁都能学会；最难的是买点没出现时管住手。
- 回撤大多来自强行交易。
- 大盈亏出现在连续盈利之后——连续盈利容易让人膨胀、无风险意识、频繁开仓。

### 1.4 入场逻辑必须首尾统一
- 中线标的：不因短期震荡恐慌卖出。
- 短线标的：被套后不被动长期持有；买入逻辑消失就果断离场。
- 不能对任何标的产生"既有希望"，不因它近期强就带有色眼镜。

### 1.5 顺势而为，不"秀肌肉"（第 63 条，9 月第 3 周最失败一周归因）
- 做交易的本质就是顺势而为：板块趋势已经明牌向上时，跟着最强方向走，而不是为了证明自己选股能力去开新板块。
- "反复陷入自证状态，忘记了交易的本质"——交易是赚钱，不是做给别人看的。
- 顺大势 + 只做自己看得懂的位置，是"操作最舒服的阶段"的共同点。

### 1.6 少看指标，减少盘中噪音（第 63 条）
- 指数稍微破位 → 担心继续下探；两次冲不破压力 → 担心回落；没有增量 → 担心高开低走。这些都是噪音。
- 操作舒服时只做两件事：① 只看大盘一个大趋势，不看盘中瞬时变化；② 只看持仓标的盘中是否与预期相符。
- 他做的是短线，利好利空关系不大，情绪才是最大敌人。

### 1.7 上升趋势中的做 T 规则
- 正替（先买后卖）：上升趋势、且距上方压力位较远 → 先进后出，降成本。
- 倒替（先卖后买）：距上方压力位较近 / 连续冲高冲不上去 → 先出后进。
- 判定标准（大哥原话转述）：上升趋势里，标的距离上方压力位较远 → 做正替；距离较近 → 做倒替。
- 做错方向的代价（第 65 条）：本应做倒替却做正替，好在标的够强没亏——"连续冲了两天都没冲上去，就该做倒替"。
- 新手纪律（大哥建议）：管不住手时，先只执行"买入、卖出"两个动作，做 T 的事以后再说（第 64 条）。

## 2. 买卖原则（可执行清单）

### 2.1 三点买入法（最核心，反复讲 5 遍：视频 54 / 56 / 60 / 61 / 62）

| 条件 | 观察点 | 含义 |
|---|---|---|
| ① 支撑位强 | 近期每次下跌都未破位（未跌破前期支撑） | 标的自身有资金护盘 |
| ② 集合竞价确认 | 已到支撑位附近；当天集合竞价稳定站在 5 日线上方，且开盘后稳定高开 | 解除"继续下跌"风险 |
| ③ 上方空间足 | 距离上方压力位（前高 / 密集成交区）足够远 | 赔率够，不是去接最后一棒 |

三条同时满足才出手；缺一条就继续观察，宁可错过，不可做错。

#### 2.1.1 强弱是相对的（横向对比）——大哥反复强调的核心选股点（第 62 条首教 + 第 67 条案例验证）
- 不要孤立看一只标的强不强，要在集合竞价时做横向对比。
- 例：当天集合竞价大多数标的水下低开，唯独它能稳定平开 → 它就是当天最强。
- 这种情况下开盘就是最佳买点，竞价进、冲高后出，比"开盘后观察再进"多赚 3 个点以上（第 67 条：当日因此少赚 3 个点被大哥点破）。
- 他以前的盲区：只看单只标的是否高开，不看全市场/同板块对比 → 大盘低开时容易恐慌、错过真强票。
- 执行动作：9:25 竞价结束后，扫一遍自选股 + 板块竞价涨跌幅排序，找"别人都跌它不跌 / 别人平开它高开"的标的。
- 强弱的参照物是当天同板块/全市场的竞价表现，不是它自己的历史分时。

### 2.2 买入时点
- 前一晚收盘后初选 5 只左右备选。
- 集合竞价阶段做最终筛选，9:25–9:35 完成进场。
- 开盘后稳定高开才确认；如果竞价高开但开盘后快速跳水，当天不接（T+1 无法止损）。
- 竞价确认的强度用相对比较：低开市场里的平开 > 高开市场里的普通高开。

### 2.3 卖出触发条件（任一满足即卖）
1. 5 日线破位（收盘或盘中明显跌破）——短线第一离场信号。
2. 与预期不符——买入时假设的走势没出现，反弹就分批走。
3. 到压力位 / 连续大阳线——利润够厚了，避免回撤。
4. 指数涨它不涨、或只象征性涨一点——弱势信号。
5. 两天拉不起来、在支撑位来回磨——随时继续下探。
6. 银行板块反扑强势、科技未见转强信号——板块轮动风险。
7. 多次冲击上方压力位不过——第 64 条"压力冲不过去必须止损离场"，第 65 条"连续两天冲不上去就该走"，宁可少赚、防止利润回撤。猜顶本身就是不对的，避免利润回撤才是关键。

### 2.4 "5 日线上 ≠ 明天一定红"的正确理解（第 63 条答疑）
- 站上 5 日线不代表次日一定红，只代表上升趋势尚未破坏。
- 上升过程中可以震荡几天，只要形态没坏，后面还有继续上涨的可能。
- 破位才有动作：盘中 5 日线破位且无法快速修复 → 短线止损离场的时候。
- 这解释了为什么"5 日线上"是买点条件而非"必涨保证"——它是趋势确认，不是预测。

### 2.5 仓位与资金规则
- 单笔一般 1–2 万（占本金 20–40%），不 all in 一只。
- 不满仓死扛；出现风险信号时分批减仓，不要一把清。
- 大哥的补仓规则：亏 20% 补 1 万，共 3 次机会；翻倍后本金加到 50 万。
- 行情复杂时主动切防御板块（创新药）避险 1–2 天。

## 3. 看盘方法

### 3.1 大盘择时（大哥给的框架，他照用，且动态调整）
> **系统实现修正（重要）**：3930 是他的**口播锚点原话**（记录用）。量化实现**不硬编码 3930**，改用动态大盘中枢 = 上证近 20 个交易日 `(high+low)/2` 均值（`compute_index_center`）；收盘低于中枢×0.99 视为破位。回测证伪：硬编码"3930 就空仓"全样本 -10.31%，比动态中枢 -4.31% 更差，故 `index_hard_anchor` 默认关闭。3930 只当观察参照，不当触发规则。
- 3930 点是多空分水岭（以收盘价为准）：收盘不破 → 上升趋势未坏，跌下来是机会；跌破 → 趋势走坏，谨慎。
- 区间判断（9 月内三次下修）：8 月底最差预期 3880–3990 宽幅震荡，跌到 3800 不要慌；9 月中 3850 是转折点/支撑位，撑得住行情就没走坏；尾盘重回 3880 之上先当小反弹看；9 月下旬 3800 附近是"黄金坑"，科技反弹未结束。
- 科创 50 锚点：1600 以下的机会要珍惜（第 65/66 条）；1630 有小缺口产生压力，小阴小阳正常（第 64 条）。
- 3930–3990 区间建议少盯盘：不盯盘就不会乱操作；收盘看一眼破没破 3930 即可。
- 大盘判断在 9 月内从"3930 单锚"演进为"3930 分水岭 + 3850 转折 + 3800 坑位"的阶梯结构，说明锚点本身也在随行情修订（见纠错 7.2）。

### 3.2 板块选择
- 只做当前最强板块的风向标，不做跟涨小弟。
- 板块轮动判断：科技什么时候起势，看银行什么时候见顶（资金跷跷板）。
- 选板块的粗标准：当天集合竞价最强、有持续催化、风向标不破位。

### 3.3 政策解读（大哥观点）
- 加息 / 降息都无所谓，最怕的是不加不降、模棱两可。
- 利空落地即是利好；不确定才是真利空。

### 3.4 个股技术观察
- 均线体系：5 日（短线生死线）、10 日（弱支撑）、20 日（中期支撑）。
- 关键位：前期高低点、密集成交区。
- 集合竞价是每日最重要的观察窗口；9:25 后必须做横向对比（全市场/同板块竞价排序），不能只看单只标的。

## 5. 复盘方法

### 5.1 日复盘模板
1. 报今日盈亏数字（精确到元）。
2. 昨日持仓标的今日走势是否符合预期。
3. 不符合预期就说清原因（板块弱？大盘？自己执行错？）。
4. 明日操作计划（持有 / 加仓 / 减仓 / 清仓 / 空仓）。
5. 大盘判断复述大哥观点（3930 / 区间）。
6. 一句情绪收尾。

### 5.2 周复盘模板
- 本周最大收获（通常是心法类，如"敢于空仓"）。
- 本周盈利 / 亏损归因。
- 下周计划与心态调整。

### 5.3 错误归因模型
- 执行层错误：犹豫、新泰极、带情绪、没破纪律 → 自己认。
- 市场层错误：板块轮动、大盘不及预期 → 归因外部。
- 方法层错误：三点买入法某条没满足就进了 → 修正流程。

> 注意：他从不归因"方法本身可能失效"，只归因"我没严格执行方法"。这一点在纠错节展开。

## 6. 其他零散但有用的点

- 5 万本金阶段，单笔亏损超过 500 元就会触发情绪警觉。
- 不做 1 分钟级别 T 加 T，T+1 制度下这种操作性价比极低。
- 创新药 / 防御板块只用来躲 1–2 天，不长拿。
- MRCC / PCB / 半导体材料 / 存储是他 9 月主做方向。
- 大哥建议观察方向：市值 500 亿以下的 PCB 标的（第 67 条）。
- "在对的道路上怎么折腾都不会亏，就是赚多赚少的事"（第 64 条，大哥原话）——方向正确比单次操作正确重要。
- 缠论看法（第 63 条答疑）：缠论不能过度神话，大哥说它有巨大缺陷，很多人学完变成"马后炮、嘴炮、实战一塌糊涂"；要用"缠论 + 关键点理论"结合才可实战。小资金想做大的现实路径就是短线（长线一年 20% 已算多）。
- 市场无增量时的态度（第 65/66 条）：只要下跌不离谱，多点耐心；等靴子落地再行动。

## 7. 专业纠错（基于公开投研常识、A 股交易制度、行为金融的审视）

### 7.1 样本量与周期严重不足
- 全部"屡试不爽"结论只来自 39 个交易日、约 86 分钟口播。
- 这 39 天恰好是 2026 年 8–9 月科技板块一波结构性行情。
- 没有经历：单边熊市、连续阴跌、板块黑天鹅、流动性危机、风格大切换。
- 结论：他的方法目前只能叫"在这 39 天里有效"，不能叫"方法成立"。

### 7.2 "3930 点分水岭"是单点锚定，不是趋势判断
- 用单一整数点位作为多空分界，是典型的技术分析安慰剂。
- 上证 3930 在这 39 天里被反复击穿，锚点一路动态下修：3930 分水岭 → 3880–3990 区间 → 3850 转折 → 3800 黄金坑；科创 50 也从"1630 缺口压力"收到"1600 以下要珍惜"。
- 锚点随行情修订本身没问题，但说明这不是可证伪的规则，而是事后的情绪表达——跌不动了就说"这里是坑"，涨不动了就说"这里有压力"。
- 真正的趋势判断需要：均线多头排列、量能结构、涨跌家数、北向 / 两融、行业轮动宽度，而不是一条线。
- 纠错：把 3930 / 3850 / 3800 当观察锚可以，当信仰不行。

### 7.3 "不猜顶底，只看确定性"是循环论证
- 他嘴里的"确定性"拆开看就是：支撑位 + 5 日线 + 高开 + 距压力位远。
- 这四条全是技术面 + 情绪面，没有基本面、没有催化剂、没有资金面验证。
- 本质上他还是在做技术分析，只是把"看图"换了个名字叫"确定性"。
- 纠错：真正的确定性需要叠加：板块催化（政策 / 订单 / 业绩）、资金结构（主力净流入 / 龙虎榜 / 北向）、市场广度。他目前完全没有这层。

### 7.4 大哥喊单 ≠ 自己的系统
- 所有大盘判断、板块切换、关键位都来自"大哥说"。
- 大哥身份不可验证、不可追责、无法回测。
- 他自己也没有讲过"如果大哥说错了怎么办"的应对规则。
- 纠错：哪怕大哥真的厉害，这种模式下他成长的是执行力，不是独立决策能力。一旦大哥不喊了，系统就空转。

### 7.5 T+1 与"5 日线破位就卖"存在制度性矛盾
- 主策略是"开盘高开进场"，但 A 股 T+1 当天不能卖。
- 如果开盘后冲高再跳水（第 57 条就是），当天只能干看，所谓"破位就卖"对当天买入的仓位无效。
- 纠错：超短线策略必须回答"开盘进场后 30 分钟内跳水怎么办"。他目前的答案是"下次别追"，没有真正的盘中止损规则。

### 7.6 板块风向标策略的风格风险
- 小资金做最强板块风向标，在板块主升期利润极快；但一旦板块退潮，风向标往往是最后补跌、跌幅最大的。
- 他自己 33 天内已经经历了科技 → 药 → 科技 → MRCC 三次切换，每次切换都伴随亏损。
- 纠错：风向标策略需要配套"板块退潮信号"（龙头破位、跟风股大面积跌停、量能顶背离），他目前只有个股层面的卖出规则，没有板块层面的退出规则。

### 7.7 资金管理颗粒度太粗
- 只说了"亏 20% 补 1 万"，没有：单笔最大亏损占本金比例、单周最大回撤线、单日最大亏损上限、连续亏损 N 笔后强制空仓几天。
- 仓位是拍脑袋的，不是按凯利公式或波动率定的。
- 纠错：5 万本金阶段靠纪律能活，但要做到 100 万，没有量化资金管理必死。

### 7.8 政策解读过于简化
- "加息降息都行，最怕不加不降"——这是把宏观当二元事件。
- 实际上 A 股对货币政策的反应取决于：经济周期位置、流动性缺口、外资流向、美债利率、汇率。
- 一句话结论对超短线无大用，真正的短线选手看的是次日开盘的实际资金行为，不是政策文字。

### 7.9 归因偏差：永远是"我没执行好"
- 亏钱后的归因永远是三类：新泰极 / 犹豫 / 带情绪。
- 从不质疑：三点买入法本身是不是在这个市场环境下失效？
- 这是典型的自我服务偏差——赚了是方法对，亏了是我没执行好。
- 纠错：正确的复盘要分两层：方法层（这个信号在过去 N 笔交易里胜率多少？盈亏比多少？）+ 执行层（我偏离规则了几次？代价多少？）。他目前只有执行层复盘。

### 7.10 合规与内容风险
- 虽然口播都说"不构成投资建议"，但他每天晒持仓、晒买卖点、报盈亏、讲选股方法。
- 在短视频平台，这种"实盘 + 教学 + 喊单"混合内容，已经处于投顾资质监管的灰色地带。
- 5 万 → 100 万的挑战叙事，本质上是流量钩子，不构成可信业绩展示。
- 纠错：作为观众，不要把他的视频当成可跟单的信号；作为学习者，把它当成一个散户的成长日记来读更合适。

## 8. 一句话总结

> 小郭这套东西，心法是及格的（空仓、纪律、不预测、执行、顺势、少看指标），选股框架是单薄的（三条纯技术面 + 竞价横向对比），资金管理是缺失的，归因是自我服务的，对大哥的依赖是结构性风险的。
>
> 39 天、5 万本金、一波科技行情，能稳定输出复盘视频、能认亏、能空仓、能自我纠错，已经超过 90% 的散户口播号。但把它当成"系统"去跟单，会在他自己还没经历过的熊市里交学费。
