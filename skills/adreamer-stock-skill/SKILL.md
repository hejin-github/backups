# ADREAMER Stock Skill

## Overview

使用"大A梦想家"交易体系（含小早啊复盘课）完成个股诊断、主力行为分析、买卖点判断与复盘。体系知识见 `references/dreamer-trading-system.md`，所有分析结论必须能回溯到该文件的某条规则；无依据不下结论，禁止臆测。

## 何时读取知识库

分析开始前必须读取 `references/dreamer-trading-system.md`，确认引用的规则原文后再动手。知识库按主题编号（核心哲学1 / 主力行为2 / 量价3 / 股票分类4 / 复盘5 / 技术结构6 / 买卖点7 / 仓位8）。

## 工作流

### 0. 交易日历校验（每次取数/复盘前必做）

A股仅在交易日产生行情。任何分析开始前：

1. 确认目标日期是否为交易日：周末（周六/周日）休市；法定节假日（元旦、春节、清明、劳动节、端午、中秋、国庆）及调休休市日无行情
2. 取数后核验K线/复盘序列的日期连续性：相邻日期缺日时，先判断是否为周末/节假日休市（正常跳过），禁止把休市日当作交易日取数，也禁止把休市日计入K线或复盘序列
3. 节假日具体日期以交易所/官方日历为准，不凭记忆推断。示例：2026-09-25（周五）中秋节休市、09-26/09-27为周末，故09-24之后下一交易日为09-28（周一）

### 1. 个股阶段诊断（主力行为定位）

对任意个股，先回答"当前处于操盘全流程的哪个阶段"：

1. 缩小K线图看整体位置：低位 / 中位 / 高位
2. 对照低位堆量三特征（地量在前、两次五连阳、量能温和递增）判断是否建仓期【第01课】
3. 对照打压式吸筹流程（破位放量、底部不再创新低、底底高）判断吸筹是否完成【第03课】
4. 对照出货三条件（看得见、想买敢买、拿得住）与涨停板位置判断是否出货期【第02课】
5. 输出阶段结论：吸筹期（不参与）/ 洗盘期（可参与）/ 拉升期 / 出货期（规避）

### 2. 量价检查【第22/29/30课 + 复盘课】

- 缩量上涨中突然放量 → 提示买盘减弱
- 持续放量换手频繁 → 情绪驱动，注意情绪退潮
- 价格创新高但量能递减 → 量价背离，出场信号
- 主升前的缩量锁筹（放量吸筹→缩量整理→关键位置企稳）→ 潜在主升结构

### 3. 买卖点与止损【第06/07/08/27课】

- 买点：五分钟缺口回补判断（日线跳空后五分钟不跌、重走上涨结构）、倒锤低吸、行业逻辑+进场图形
- 卖点：高位长上影/避雷针、量价背离、四连阴+反弹不上去
- 止损唯一理由：买入逻辑消失；技术买点止损设缺口下沿

### 4. 板块与主线判断【复盘课】

- 看涨幅榜/跌幅榜，盯板块价格与成交量
- 价格涨+量放大的板块=当下主线；结合资金流向、政策、行业消息判断持续性（容量小+短期逻辑=一日游）
- 分清股票类型：情绪股 / 合力股 / 趋势股，操作逻辑不同

### 5. 复盘报告输出

输出复盘报告时包含：情绪与股价位置（先手/后手判断）、主线板块与持续性、当日异动个股按体系规则归类（吸筹/洗盘/出货/拉升）、次日关注点。引用体系规则时标注来源（如【第01课】【复盘课】）。

## 硬约束

- 禁止臆测：每个"主力意图"判断必须标注依据的体系规则；数据类结论（股价、量能、涨跌幅）必须来自实时行情并标注信源
- 禁止荐股：体系自带"专注技术，不推荐"，输出必须附"不构成投资建议"
- 禁止图形机械对照：同一图形可能洗盘也可能出货，必须结合位置与量价行为综合判断
- 区分两类内容：体系观点（引用本知识库，注明出处）vs 市场事实（实时数据，注明来源）
- 交易日对齐：行情与K线仅取A股交易日数据，自动跳过周末与法定节假日（含调休），禁止取用或计入休市日数据；节假日日历以官方公布为准
