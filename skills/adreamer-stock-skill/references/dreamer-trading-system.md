## 1. 核心交易哲学

### 1.1 对手盘思维
- "我们的对手对我们非常了解，这就是绝大部分散户亏损的原因。我们不了解对手，但是对手了解我们。"
- 方法论：从主力视角拆解操盘全流程，先了解对手，才能找到战胜他们的方法
- 分析任何个股的第一步：问"如果我是主力，这个走势对我有利吗"

### 1.2 看大盘吃饭，仓位为王
- 震荡磨底行情：最多三成仓（轮动飞快，方向踩对但时间点不对一样亏损）
- 单边行情：重仓干；没有单边行情：韬光养晦，保持盘感
- 每年只需抓住1-2波行情，其余时间用来学习和清仓，避免反复磨损账户

### 1.3 模式内交易
- 只做自己能看懂的股票，不碰看不懂的图形
- "五千多支股票，难道找不出你能看懂的吗？"

### 1.4 本质思维，不背图形
- 图形一模一样，可能是洗盘也可能是出货——看K线/分时本质是看背后的行为，不是图的样子
- 要琢磨：这个现象背后合不合理？正不正常？
- 禁止机械化"图形A+条件B=结论C"的对照式判断

### 1.5 先手转后手（【复盘课】）
- 股市基本逻辑是"先手转后手的钱"，是一场击鼓传花的游戏（任何市场都一样，由人的贪婪和恐惧决定本质）
- 股价永远比普通人的想法跑得快；要赚钱必须抢在别人之前行动
- 大众认知变化路径：怀疑 → 慢慢认可 → 抢着买；当能买的人基本买完、没人进场 → 股价见顶
- 下跌同理：情绪宣泄完毕，下跌行情反而要停了

### 1.6 松弛持股（【第42课】）
- 交易紧张的根源：害怕失去、害怕犯错；松弛感不是天生的，建立在深刻底层逻辑之上
- 松弛持股第一步：把选好标的的底层逻辑写在纸上，找不到就不做、空仓、先找原因（【第42课】）
- 抓住主要矛盾：至上而下选股（大盘→板块→个股→进出点）；学的越多看到越少是因为被分时波动干扰；分时最大作用是做T找高低点、判断主力意图、找精准点位；越小级别越不稳定，周线月线走好胜率更高（【第42课】）
- 主要矛盾解决方法：套牢盘大山要么砸天量直接拉，要么以时间换空间震荡磨去套牢盘耐心（【第42课】）
- 板块识别：把三个月内资金在各板块之间的流转摸清楚，小的板块轮动不用理会，大的板块有异动回调就是介入机会（【第42课】）
- 松弛持股战术："打得赢就打，打不赢就跑"；不要被成本深度绑架；不要做无效交易；连续大胜要停下来（赢多了会飘、会贪、会轻敌，三天回吐一半利润）（【第42课】）
- "技术好学半年足以，但是真正能够做到闲庭信步，路还很长"（【第42课】）

### 1.7 交易体系底层逻辑（【第64课】【第68课】）
- 股票是从宏观到微观都要求踏踏实实地掌握的一门技能（【第50课】）
- "模式为纲，纪律为尺，严控回撤"（【第60课】）
- 交易之前一定要做好计划：止损线设好，止盈根据走势和分时结合判断；对了就是对了，错了就立刻止损，止损错了也不后悔，总结经验优化系统（【第61课】）
- 股市不是赚快钱的地方，是技术+心理双重考验；做股票不是顿悟，是渐悟的过程（【第52课】）

## 2. 主力行为分析体系（核心）

### 2.1 主力操盘全流程
选标的 → 吸筹 → 洗盘 → 拉升 → 出货

### 2.2 打压式吸筹【第03课】
散户**不参与吸筹阶段**，只需要能看懂、能分辨。

流程：
1. 一路下跌不给希望：连续下跌结构，散户死拿、躺平
2. 击穿支撑让散户绝望：在关键位置击穿所有支撑位，配合非系统性小利空，放量跌破平台
3. 散户恐慌割肉、主力接盘：破位放量=散户在卖、主力在买
4. 底部不再创新低：接完筹码后底部慢慢抬高（底底高）
5. 反复震荡洗筹：洗掉抄底散户，等待拉升时机

识别要点：看位置（下跌后低位）、看量价（关键位置破位放量）、看形态（多次打到同一位置不再往下）、看筹码变化（上方筹码逐步移到底部）。

主力砸盘时机：喜欢借大盘调整/板块利空顺势砸（散户归因于市场，不会怀疑主力）；拉伸同样等时机。

### 2.3 低位堆量（主力建仓信号）【第01课】
堆量位置含义：低位堆量=主力吸筹；中期堆量=洗盘和蓄力；高位堆量=出货和派发。

三大特征：
1. **地量在前，堆量在后**：下跌后出现地量（空头力量衰竭，该卖的卖完了）；地量量化=较前期高峰缩量50%以上，好的缩到30%-40%；无缩量直接放量的，空头动能未释放完毕，风险大
2. **两次五连阳堆量**：堆量期间阳线为主、阴少且实体小；连续小阳/中阳，涨幅3个点左右不宜过大（过大会引跟风盘）；两次五连阳间隔约10个交易日最佳、越短越好；第一次=试探建仓+测试抛压，第二次=确认主动吸筹
3. **量能温和递增、均匀堆积**：不能忽大忽小、杂乱无章（说明多空分歧大）；温和放量=主力持续主动买入，不是对倒作假

补充逻辑：放量可做假（对倒），缩量无法做假；地量是低位堆量的前置条件。

### 2.4 洗盘【第03课】
- 与吸筹最大区别：**吸筹不参与，洗盘可参与**
- 目的：洗掉浮筹，逼迫前期获利盘下车
- 识别关键：连续大阴线/大阳线都是主力行为
- 洗盘后往往有"倒车接人"的买入机会

### 2.5 出货【第02课】
"吸筹你顶多被套，洗盘你顶多卖飞，出货就是真金白银的亏。"亏大钱往往在牛市——涨得很好、意气风发毫无警惕时被套。

**出货三条件**：
1. 让散户看得见：涨停板、跳空涨停、大阳线、突破形态=主力的"广告"
2. 让散户又想买又敢买：走势好看（均线多头、MACD金叉、突破平台）+讲故事（利好、热点、题材）
3. 让散户买完能拿得住：股价跌不下去、有支撑、有反弹

出货流程：
1. 前期吸筹→洗盘→吸筹→洗盘，洗掉前期获利盘（关键点：**四连阴+反弹抽不上去=逼迫获利盘下车的出场点**）
2. 打广告：连续涨停突破新高，吸引全市场关注（涨停板的意义不是想拉升，是告诉全市场"我来了"）
3. 给机会：涨停后回调到关键点位"倒车接人"，再继续涨停突破
4. 高位箱体震荡：跌到支撑位就反弹、时不时拉涨停，稳住散户持有

关键判断：把图形缩小，分析涨停板在整个走势中所处的位置——高位放量涨停，大概率是出货不是吸筹。

### 2.6 各阶段洗盘核心逻辑（【第38课】）
- 洗盘目的：洗掉浮筹、逼迫前期获利盘下车；洗盘后往往有"倒车接人"的买入机会
- 洗盘识别：连续大阴线/大阳线都是主力行为；散户不参与吸筹阶段，只需要能看懂、能分辨
- 洗盘 vs 出货核心区别：吸筹你顶多被套，洗盘你顶多卖飞，出货就是真金白银的亏（【第65课】）

### 2.7 主力洗盘内核（【第40课】）
- 主力洗盘手段多样：恶性阴线连续打压洗盘、破位洗盘（金针探底）、拉高吸筹后打压、涨停板炸板泄压换手洗盘
- 涨停板泄压（炸板）：主力短暂撤单开板，跌幅小（2个点以内、不下黄色均线）= 换手洗盘+强承接，洗出不坚定获利盘同时新资金进场，提高市场平均持仓成本（【第57课】）
- 破位洗盘关键：跌破止损位不要第一时间走，要看能否迅速拉回并带量上攻；如果反抽无力再离场（【第59课】）

### 2.8 洗盘还是出货（【第65课】）
- 判断方法：把图形缩小，分析放量位置；高位放量涨停大概率是出货不是吸筹
- 出货三条件回顾：让散户看得见（涨停板/跳空涨停）、让散户又想买又敢买（走势好看+讲故事）、让散户买完能拿得住（跌不下去有支撑）
- 一字板上来没有出货量 = 主力没有出货机会；假阴线后第二天解放所有买盘 = 主力要寻求更高高度出货（【第44课】）

### 2.9 辨别试盘K线（【第70课】后半段付费保护未提取）
- 试盘线：打到前期爆量高点、形成长长上影，是主力资金试盘行为（不一定想一次就过）（【第51课】提及）
- 【第70课】付费视频，转写只提取到"形成惯性思维"处，后半段付费保护未提取

### 2.10 读懂筹码峰（【第71课】后半段付费保护未提取）
- 巨量堆量区不买：巨量堆量区=套牢盘逢高卖+抄底盘逢高卖，量越大分歧越大、筹码越松动；高位巨量堆量区要等缩量（最起码缩到一半）才可以关注（【第58课】）
- 筹码从底部上移到平台 = 市场整体持股成本提高（【第58课】）
- 【第71课】付费视频，转写只提取到"先是下跌之后"处，后半段付费保护未提取

### 2.11 跟庄选股法（【第72课】后半段付费保护未提取）

## 3. 量价体系【第22/29/30课 + 复盘课】

### 3.1 根本原则
"价格才是最重要的，成交量是为股价服务的。复盘的核心是看股价的趋势，成交量只是帮你分析的重要工具。"（裸K观盘，均线仅参考）

### 3.2 缩量涨 vs 放量涨（背后逻辑不同）
- 一直缩量涨，某天突然放量 → 买盘变少，上涨势头大概率弱下来，要小心
- 一直放量、换手频繁 → 多数靠情绪撑，情绪冷下来行情就结束

### 3.3 主力与缩量上涨完整链路（【复盘课】）
放量吸筹 → 缩量整理（筹码锁死）→ 价格在关键位置稳得住 → 风口来临时缩量上涨（涨得轻松）→ 涨到一定程度放量派发

### 3.4 方法论
不同的上涨结构不用对比量、不用教条。

### 3.5 量价二波上车法（【第44课】）
- 一字板上来没有出货量 + 假阴线放量分歧 + 第二天解放所有买盘（最高价高于前一天最高价）= 主力要寻求更高高度出货，后面有更大空间
- 长阴短柱：价格跌很多但量柱缩量 = 量价移动，主力没有出货
- 回调深的股票需要长时间筹码转换（以时间换空间），资金用在这里不划算；要找回调不深的（【第44课】）
- 过前高一定要放量；如果没有放量，就在回踩之后寻找合适时机继续放量突破（【第50课】）

### 3.6 量价为主分时为辅（【第58课】）
- 涨停板泄压（炸板）：跌幅小、不下黄色均线 = 换手洗盘+强承接
- 缩量跳空低开阴线出现在下跌末端 = "该弱不弱就是强"，特别值得关注（【第58课】）
- 分时开盘单边下跌：观察最大量后面还有没有低点；如果后面没有新低、走平向上带量上攻 = 机会（【第58课】）

### 3.7 同一结构 vs 不同结构量价背离（【第43课】【第47课】【第50课】）
- 同一上涨结构里出现量价背离（价涨量缩）= 止盈信号；允许第一天背离，第三天仍未修正就出局
- 不同上涨结构之间：位置越高量越缩 = 价涨量缩，才是最好的形态（缩量上涨还会涨）；越往上涨量越来越多 = 分歧没解决，上涨空间变小
- 等哪天突然放量的时候，基本上就快要见顶了（【第47课】）

## 4. 股票分类：三种上涨逻辑【复盘课】

| 类型 | 定义 | 特征 |
|------|------|------|
| 情绪股 | 靠题材炒起来 | 涨跌都快；可能一刀流，拉上去直接没了 |
| 合力股 | 散户+各路游资一起推 | 走完一波换手可再接力一波（"得散户者得天下"） |
| 趋势股 | 顺趋势规律向上 | 沿均线慢慢涨，一眼可辨 |

操作顺序：找准板块 → 分清股票类型 → 找准当下主流方向，交易才有据可依。

## 5. 复盘方法【复盘课】

- 复盘是交易基石："不会复盘，就像高速开车没有车灯，只能靠感觉走，非常危险"；每天收盘后应花数小时
- 为什么要复盘：只有复盘才知道股价变化；散户感受到的是情绪，情绪永远比股价慢半拍
- 具体步骤：
  1. 看涨幅榜、跌幅榜
  2. 重点盯板块的价格和成交量：资金往里冲的地方=赚钱的地方；资金往外跑的地方=容易亏钱的地方
  3. 先研究板块再找标的（单标的量价人为痕迹多，板块走势更稳更靠谱）
  4. 价格上涨+成交量放大的板块=当下主线；脱离主线的交易难赚钱
  5. 结合资金流向+政策大环境+行业消息判断上涨势头能否持续、同类标的是否跟上
  6. 反例识别：小板块、容量少、短期逻辑的上涨往往是一日游

**操作规范（Skill 补充，非课程原话）**：复盘仅针对交易日。周末与法定节假日（元旦/春节/清明/劳动节/端午/中秋/国庆及调休）休市无行情，K线与复盘序列自动跳过休市日，禁止把休市日当作交易日取数或计入序列；节假日日期以交易所官方日历为准（示例：2026-09-25 中秋休市，09-24 后下一交易日为 09-28）。

### 5.1 复盘自己交割账单（【第52课】）
- 终极复盘大招：从复盘自己的交割账单开始，每天五支标的，从最前面开始用本子记下来
- 第一步：缩小看K线图，用上帝视角整体观察当初入场位置（底部吸筹/震荡上行/加速拉升/主力出货区）
- 第二步：打开所在板块，看当时板块处于什么位置
- 第三步：列表格填项——大盘位置、板块是否主线/大容量/长期逻辑、个股是龙头还是跟风还是后排低位、具体买卖点是否符合买点模式
- 假设把现在的你再放到当时，你还会不会在这个点动手？哪个点你认为是进场好时机？
- 只要一个月，认知会突飞猛进，盘感越来越好（【第52课】）

### 5.2 涨停板复盘法（【第44课】）
- 每天把涨停板收入股池进行观察；观察涨停后是强势继续拉升还是回踩再拉升、回踩深度有多深
- 周末翻股票做功课；可用通达信/同花顺文字筛选功能（如"半年内涨停超过三次"、剔除ST）从五千多支缩小到几百支（【第50课】）

## 6. 技术结构（K线与趋势）【第04/15/31课等】

- 上涨结构 vs 下跌结构：上涨回调不破低，下跌反弹不过高
- 一路下跌后**第一个上涨结构不要做**，做第二个、第三个（一小段止跌不一定改变大方向回调）
- 顺势而为；多空博弈看日周月共振
- 上引线战法、大阴线洗盘法（K线形态识别）

### 6.1 结构的力量（【第43课】）
- 上涨结构形式：锐角回调不破起涨点（阳包阴入场）、平缓回调（跳空上涨后涨停打开仅回调到缺口上方=主力控盘强）
- 优中选优：找调整幅度浅且强势的股票；30多个交易日股价翻三倍的案例=调整越来越浅、角度越来越平、最后横向调整，随后加速
- 复合结构：上涨回调再上涨再回调，回调过程中有小结构再起涨；五分钟找止损点常用（缩到地量且价格没跌破起涨点时买入先手）
- 主力惯用手法：跌破止损点快速收回（尖角拉回=主力故意诱空）；这种加仓点只适合心态稳的同学（【第43课】）

### 6.2 上涨基因（【第43课】）
- 同一结构里出现量价背离要减仓或出局；不同结构里量越来越少才是好形态
- 当倒垂下面已经有六个点时不要追（止损点太高）；要找止损位扎实、入场点离止损位近的买入点（【第43课】）

### 6.3 跳空缺口原理（【第50课】）
- 跳空缺口=筹码真空区，没有筹码交换；形成原因是一致看多（如小区突然出地铁+重点中学利好，房价从1万直接跳到1万5）
- 缺口强支撑前提：形成原因短期内一定要成立；如果回补了缺口=上涨逻辑被推翻，绝对不是进场点而是止损点
- "逢缺必补、回补再买"是完全错误的（【第50课】）

### 6.4 集合竞价原理（【第46课】）
- 集合竞价=盘后市场对个股的态度，由参与者共识决定；以最大成交量优先原则决定开盘价
- 9:15-9:20：可以撤单，主力常挂巨量涨停单诱多后瞬间撤单，这五分钟报价不算数
- 9:20-9:25：不能撤单，价格变动才是真实信号
- 9:25-9:30：冷静期，不接受新申报和撤单
- 9:20前挂很多涨停买单但9:20后没有了、价格直线下跌=主力诱多，开盘后谨慎做决定（【第46课】）

## 7. 买卖点体系

### 7.1 买点
- 倒锤（倒垂）战法低吸：弱势行情专用【第08课】
- 行业逻辑+进场图形【第14课】；牛股基因【第20课】；短线选股【第32课】
- **五分钟进场点技巧**【第03课】：
  - 日线上涨回调后跳空下跌，五分钟看跌不下去、重新走上涨结构=买点
  - 往上涨的缺口不回补且再走上涨结构=买点
  - 止损设在缺口下沿

### 7.2 卖点
- 主力不走我不走【第06课】；分时篇卖点【第07课】；学会止盈、顶峰留一寸【第11课】
- 出场信号：
  - 上涨结构中高位出现长上影线、避雷针=走
  - 量能越来越少但价格创新高=量价背离，走
  - 四连阴+反弹不上去=关键出场点
- 每步都要做好防守：不能确定哪个上涨结构后面有更大涨幅

### 7.3 止损
- **止损唯一理由：买入的逻辑没有了**【第27课】
- 设好止损建立交易自信

### 7.4 止损逻辑（【第55课】）
- 止损两个方法：①找到主力资金的支撑点（一定要是主力资金的支撑点）；②不及预期的止损
- 主力资金支撑点识别：打开一分钟图缩小，下跌过后主力资金大单拉升的堆量区（一根一分钟4000多万=散户做不到）；跳空缺口下沿+天量一分钟K线底部+上涨结构打到的线=支撑力极强
- 破位不要一破就走：如果破位但短时间快速拉回（一分钟破位放巨量=承接非常好），恰恰证明止损线背后逻辑是对的，持股待涨；如果破位反弹没有力度再走（【第55课】）
- 日线级别止损设在上涨结构起点/高点也合理，但更倾向于到更小级别找主力资金支撑点（细节做得更细）（【第55课】）

### 7.5 分时出场点（【第53课】【第56课】【第66课】）
- 高位直线拉升、均价不跟：先走一半；量能尾缩、反弹高点无量时出另一半（【第48课】）
- 贴边杀：开盘第一分钟直线下杀放巨量=关二爷青龙偃月刀，赶紧跑路；三个点无脑止损或第一次反弹无量时出场（【第48课】）
- 五种逃顶分时：①早盘均线以下波动小，突然垂直过山车一两根孤量拉上去不封板=诱多出货；②早盘下探后反复拉出高度再回调，每次都是孤量=高位出货；③早盘直接杀四五个点横盘后直线拉板=吸下面获利盘+上面套牢盘，第二天大概率低开（【第53课】）
- 高位震荡横盘（接近涨停但不拉）：画止盈线，跌破就离场（【第53课】）
- 两点半以后进场：大盘不好时最好两点半以后再决定是否操作；前面堆量主力不再买、自由落体时量缩到特别小（抛压小），买在离均线远一点的地方（【第45课】）

### 7.6 五分钟逃顶法（【第49课】）
- 短线必看周期：一分钟、五分钟、一小时
- 五分钟出现下跌结构（上涨结构起点被跌破、反弹无力）=分批止盈；能避免90%以上的暴跌
- "能赚七毛的不要赚一块，只赚七毛留三毛继续"；做股票最重要的是保住本金、让复利不断扩大，不是赚到最后一个铜板（【第49课】）

### 7.7 好分时 vs 坏分时（【第54课】）
- 好分时：①平开下探拉到3%左右震荡再拉封板（等均线跟上来、洗盘）；②上涨中拉高洗盘（红柱绿柱间隔开、头头高底底高）
- 坏分时：①单根阳量拉高后抖抖抖往下出货（头头低底底低下降通道，通常出现在阶段顶/出货时）；②早盘一分钟直线拉到七八个点然后下来（砸穿均线无条件止损，不用等反抽）（【第54课】）

### 7.8 好的进出点（【第67课】）
- 进场后设止损、出完后观望：按照逻辑做出进场决定但股票没有走出预期强势时，要么设止损继续等，要么先出场观望，等再次起量结合分时决定入场点
- 止盈不固定：更取决于分时走势和临盘判断（【第56课】）

### 7.9 基本功之寻找进场点（【第69课】）
- 上涨结构后阳包阴（带量）=买点；止损设在这一波筹码集中区下沿
- 倒锤线先入先手（1%仓位），止损设在关键线；第二天考验低点迅速收回或不打破低点=强势结构成立可加仓（【第48课】）
- 四根阴线回调是宝：连续上涨是主力行为、连续下跌也是主力行为；但回调时不要接飞刀，要等倒锤线信号（【第51课】）

## 8. 仓位与行情阶段【第02/05课】
- 大盘单边行情：重仓；震荡磨底：最多三成仓；其他时间：学习+清仓+保持盘感
- 每年1-2波行情抓住即可

### 8.1 连跌行情应对（【第48课】【第49课】）
- 竞价辨别市场情绪：看涨跌比、数涨停跌停、看大盘整体情况；竞价很弱就管住手，盘中盯情绪是否有弱转强趋势
- 90%以上个股跟随大盘；当天盘面差就即时减仓，只能用轻仓试错
- 大盘没有止跌时：减仓一半以上、减少标的操作、只做确定性高的、轻仓试错；大盘止跌出阳才是好机会（【第49课】）
- 看大做小：大盘 > 板块 > 个股；管住手、执行交易纪律，不管什么行情都不会被套（【第48课】）

## 9.5 小早啊补充课（【xz13课】~【xz17课】）

### 9.5.1 震荡市场手痒与三条规矩（【xz13课】）
- 股价反应的不是业绩本身，而是真实发生的与市场原本预期之间的差（业绩好但股价跌=提前买进去了；业绩差但股价涨=利空出尽）
- 市场原本预期被资金面、政策、消息、情绪、别人怎么想共同拉扯，强弱每天都在换；凯恩斯选美比喻：你要猜的不是哪个最好，是大家会觉得哪个最好
- 手痒多半跟看好什么没关系，是因为不确定、难受，想抓点什么在手里；很多操作是为了缓解焦虑（吃安慰剂），不是为了赚钱
- 动手前三问：①这个位置我有没有信息优势（跟所有人手机上看到的一样就不叫优势）；②这次动是赚确定性的钱还是赌随机性；③我要是不动到底会损失什么（没优势的机会错过了不算损失，真正亏的是在没把握的位置把成本越做越高）
- 震荡市场不讲求最快的人，讲究坐得住的人；在你看不懂的地方少动手，把子弹留在你看得懂的地方（【xz13课】）

### 9.5.2 交易四阶段与知行合一（【xz14课】）
- 交易经历四阶段：①什么都不懂瞎操作熟悉流程；②对市场有理解框架；③慢慢摸到盘感、理解底层逻辑；④对每次操作有具体感知、清楚背后动机、形成自己的体系
- 经验形成不是待在市场里就自动拥有，而是从一次次尝试中摸索出底层逻辑并不断验证
- 避免回撤就是增加盈利；股市盈利是概率统计，盈利时多盈利、亏损时少亏损就能持续盈利
- 新手小白先最小成本练习，对正负反馈有感知后慢慢形成体系；体系是操作出来的不是规划出来的，3-5个月能了解市场（【xz14课】）

### 9.5.3 失败越快成功越快（【xz15课】）
- 做事拖延和失败观有很大关系；失败越快成功越快，要尽可能快速拿到负反馈
- 先干型：零基础情况下先买两笔，管他亏赚先干了再说，结束后根据结果找规律
- 入场点有时准有时不准=还没摸透规律=不熟练=做少了；把样本从十次提升到一百次，就能排除不准因素找到精准入场点
- 少研究悲观情绪，多实践才能快速赚钱（【xz15课】）

### 9.5.4 多维博弈与周期共振（【xz16课】）
- 不是技术没用，是用一维单线思维看多维博弈的A股市场；看K线、看业绩、看美股、看宏观然后机械买卖=赌运气
- 多维周期缺一不可：①宏观大周期（美联储加息降息以年为单位，看不懂则所有短线分析都是盲人摸象）；②板块产业周期（同一逻辑在周期上行期是翻倍行情，退潮期是陷阱）；③A股年度轮动周期（一年一到两波大行情）；④时间+空间双维度（空间到位不代表能反转，时间周期没磨够、情绪没出清、筹码没沉淀，再便宜也只会阴跌）；⑤资金情绪博弈（赚钱周期来时增量资金汹涌、容错率极高；退潮时所有逻辑技术业绩全部失效）
- 五六月份科技大行情=宏观周期+板块周期+资金情绪+时间空间+事件催化全部共振的抄底红利；当下情绪退潮周期，哪怕空间跌出性价比，调整时间不够、情绪冰点没到、资金没有回流信号，所有单一利好撑不起行情（【xz16课】）

### 9.5.5 短线止盈与看短做短（【xz17课】）
- 做短线一定要在入场之前设置好止盈点；不要看短做长（本来盈利的票最后反而亏损=没有设置好止盈点）
- 盈亏同源：被资金集中炒作的票，情绪高涨时待在里面不出来，炒作结束资金一走股价打回原形，原本能赚三五个点最后亏二十个点
- 长线按季度兑现，只有行业逻辑被破坏或公司基本面变化才走；短线按小时博弈，侧重市场情绪和资金炒作；二者底层逻辑完全不同，策略也有区别
- 宁愿卖飞也不肯亏钱是相反操作思路；但要警惕从一个极端走向另一个极端（曾经盈利过的票抱有恐慌情绪生怕利润回吐，导致短线变超短、一夜持股占比过高）（【xz17课】）
