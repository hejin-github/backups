# MANTTOU Stock Skill

## Overview

使用"馒头来啦"抖音教学视频体系完成个股技术面入门分析、量价解读、做T时机判断、涨停次日决策、复盘整理。体系知识见 `references/manttou-knowledge.md`，所有分析结论必须能回溯到该文件的某条规则；无依据不下结论，禁止臆测。

分析开始前必须读取 `references/manttou-knowledge.md`，确认引用的规则原文后再动手。知识库按主题编号（基础认知1 / 量价体系2 / 资金筹码3 / 技术指标4 / 分时5 / 交易策略6 / 复盘心态7 / 黑话8）。

## 工作流

### 0. 交易日历校验（每次取数/复盘前必做）

A股仅在交易日产生行情。任何分析开始前：
1. 确认目标日期是否为交易日：周末休市；法定节假日及调休休市日无行情
2. 取数后核验K线序列的日期连续性：相邻日期缺日时，先判断是否为周末/节假日休市（正常跳过），禁止把休市日当作交易日取数
3. 节假日具体日期以交易所/官方日历为准，不凭记忆推断

### 1. 量价快速诊断【主题2】

对任意个股，先回答"当前量价状态是否健康"：

1. **看量价确认还是异常**：动力（成交量）和结果（K线涨跌幅）是否匹配？有动力有结果=量价确认；有动力没结果或没动力却有结果=量价异常，重点警惕（尤其在趋势末端）
2. **看换手率档位**：<1%冷清观望；1%-3%正常跟踪；3%-5%升温留心；5%-15%热点博弈；>15%提防派发（高位横盘破25%=出货嫌疑大）
3. **看量比档位**：<0.8跳过；0.8-1.5平淡；1.5-3温和放量（配合股价上涨=健康）；>3机会风险拉满新手谨慎
4. **看地量是否成立**：不能只看单日缩量，要过三问——从哪里缩下来的（必须是深跌后低位）、缩了多久（至少几周三个月低量区间）、缩完之后有没有温和放量上涨确认

### 2. 资金与筹码定位【主题3】

1. **筹码峰三数据**：获利比例>80%=抛压大别追高；<20%=下跌动能不足等反弹；筹码集中度<15%=容易走主升
2. **筹码峰四形态对号**：低位单峰密集=优选买点（放量突破低吸）；高位单峰密集=避雷不接盘；上下双峰=区间套利；筹码发散=坚决观望
3. **内外盘六法则**：外盘>内盘但股价跌=诱多出货赶紧逃；外盘>内盘量价齐升=真实做多安心持有；内盘>外盘但股价涨=反常小心；内盘>外盘放量下跌=主力出逃；双盘极小极度缩量=别轻易入场；双盘持平横盘=先观察
4. **委比反直觉逻辑**：上涨时委比偏绿（+40~+60低吸区间）更好；下跌时委比偏红更好；冲到+70以上留意回调，跌到-70以下留意反弹

### 3. 技术指标交叉验证【主题4】

1. **均线体系**：5日线（攻击线）线上不轻易卖线下不轻易买；10日线（操盘线）没效跌破=波段未走完；20日线（分水岭）有效跌破=提高警惕；金叉=留意做多信号，死叉=留意走弱
2. **MACD**：金叉在0轴下=由弱转强，0轴上=强势加速；死叉在0轴上=回调风险，0轴下=下跌延续；顶背离=虚涨可能反转，底背离=空头力尽可能反弹；震荡行情中金叉死叉多为无效信号
3. **K线形态**：十字星=变盘信号先等方向；长上影=压力位附近谨慎；长下影=支撑位附近；六种底部组合（启明星/平底/锤形/看涨吞没/曙光初现/旭日东升）看涨强度依次参考

### 4. 分时与涨停判断【主题5+6】

1. **七种分时走势识别**：拉高洗盘（高点低点同步上移）=耐心持有；拉高出货（高点低点同步下移+急拉诱多）=警惕；温和上攻（踩均价线企稳）=健康；冲高诱多（暴力冲高后跌破均价站不回）=跑路信号；尾盘直拉=偷袭弱势；阶梯上行=持续性好；高开砸盘（高开低走碰均线就压）=谨慎减仓
2. **涨停次日决策**：计算封单成交率（收盘买一封单量÷全天成交量×100%）；>30%安心持有；15%-30%见好就收；5%-15%冲高就分批了结；<5%做好离场规划；<1%更不需犹豫

### 5. 做T与解套【主题6】

1. **做T三方法**：分时均线偏离法、量价背离法、MACD背离法；多个指标共振信号参考价值更高
2. **解套四步**：破位先减仓保现金 → 深跌缩量时低吸攒筹码 → 反弹到压力位果断兑现 → 回踩不破位继续滚雪球
3. **做T三前提**：不能是基本面爆雷股；板块逻辑不能彻底熄火；必须有纪律（低吸前想好卖点，卖出后想好接回点）

### 6. 复盘输出【主题7】

输出复盘报告时按八步框架：市场情绪→连板梯队→板块结构→主力资金→亏钱效应→市场消息→重点个股→执行计划。引用体系规则时标注来源（如【mt_04八步复盘】【mt_08地量】）。

## 硬约束

- 禁止臆测：每个"主力意图/走势判断"必须标注依据的体系规则（对应知识库某条）；数据类结论（股价、量能、涨跌幅、换手率、封单成交率）必须来自实时行情并标注信源
- 禁止荐股：输出必须附"不构成投资建议"
- 禁止图形机械对照：同一形态在不同位置（高位/低位/半山腰）含义完全相反，必须结合价格位置与量价行为综合判断
- 区分两类内容：体系观点（引用本知识库，注明出处视频）vs 市场事实（实时数据，注明来源）
- 交易日对齐：行情与K线仅取A股交易日数据，自动跳过周末与法定节假日（含调休）；节假日日历以官方公布为准
- 地量/缩量判断必须过三问框架，不能只看单日量柱下结论
- MACD/均线金叉死叉在震荡行情中默认视为无效信号，趋势行情中才参考
